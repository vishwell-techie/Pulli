# நிழலாட்டம் (Nizhalattam)

**English:** [README.md](README.md)

*நிழலாட்டம்* என்றால் நிழல் பாவைக்கூத்து. இது Pulli-யின் platformer காட்சி
விளையாட்டு: பக்கவாட்டில் நகரும் ஒரு அதிரடி விளையாட்டு, ஓட்டம் ஓட்டமாக
(run-based) ஆடப்படுவது, தமிழிலும் ஆங்கிலத்திலும். கன்சோலை அதன் எல்லை வரை
தள்ளுவதற்காகவே கட்டப்பட்டது: ஒரு முற்றமும் ஆறு கதைகளும், ஒவ்வொன்றுக்கும்
தனி ஓவியங்கள்; ஏழு தலைவர்களும் (boss) அவர்களுடைய நிழல்களும்; அணிந்துகொள்ள
எட்டு வேடங்கள்; ஒவ்வொரு கதவுக்குப் பின்னும் முன்கூட்டியே படிக்கப்படும்
அறைகள்; ஆடும்போதே கட்டப்படும் அறைகள்; மூன்று சேமிப்பு இடங்கள்; இசையும்
ஒலிகளும்.

உடைந்து ஒட்டுப்போட்ட ஒரு கோமாளிப் பாவை, **கோமாளி** (Jester), நிழல்
பாவைக்கூத்து அரங்கின் ஒளிரும் திரைத்துணியைக் கடந்து அதன் கதைகளின்
உலகுக்குள் நுழைகிறான். குழுவின் மற்ற பாவைகளை **பாவை அரசன்** அங்கே
சிறைவைத்திருக்கிறான்; ஒவ்வொன்றையும் ஒரு கதையில், தான் திணித்த ஒரு வேடத்தில்.
கோமாளி ஒவ்வொரு கதையையும் போரிட்டுக் கடக்கிறான், தான் வென்ற பாவைகளின்
வேடங்களை அணிகிறான், அவர்களை ஒவ்வொருவராக வீட்டுக்குக் கொண்டுவருகிறான்.

## விளையாடுவது

முதலில் desktop host-ஐக் கட்டவும் (repository-யின் README-ஐப் பார்க்கவும்),
பிறகு repository-யின் வேரிலிருந்து:

```bash
python3 tools/pulli.py run examples/nizhalattam
```

இசையோடு விளையாட்டை pack செய்ய ஏறக்குறைய ஒரு நிமிடம் ஆகும் (pack செய்யும்போதே
இசை சுருக்கப்படுகிறது). ஒவ்வொரு முறையும் pack செய்யாமல் அதே package-ஐ மீண்டும்
விளையாட:

```bash
python3 tools/pulli.py pack examples/nizhalattam build/nizhalattam.pulli
python3 tools/pulli.py run build/nizhalattam.pulli
```

| D-pad இடம் / வலம் | ← → | ஓடு; பட்டியல்களிலும் அட்டைகளிலும் நகர் |
| D-pad மேல் | ↑ | கதவு வழியே போ; பெட்டி, கடை, கிழிசல், அல்லது பெட்டகத்தைப் பயன்படுத்து |
| D-pad கீழ் + A | ↓ + Z | மெல்லிய தரை வழியே கீழே இறங்கு |
| A | Z | தாவு (அழுத்திப் பிடித்தால் உயரமாக); இரட்டைத் தாவலுடன் காற்றில் மீண்டும்; சுவர்த் தாவலுடன் சுவரிலிருந்து; பட்டியல்களில் தேர்ந்தெடு |
| B | X | அணிந்திருக்கும் வேடத்தால் அடி (வீரனாக B-ஐப் பிடித்தால் கனமான வெட்டு; வில்லாளியாகப் பிடித்தால் துளைக்கும் அம்பு); பட்டியலை விட்டு வெளியேறு |

| Y | S | உருளு: அடிகளின் ஊடே போகும் ஒரு விரைவான தப்பல் |
| L / R | Q / W | வேடம் மாற்று: உள்ளே வரும் வேடம் வரும்போதே அடிக்கும் |
| START | Enter | நிறுத்து |
| SELECT | Right Shift | நிறுத்தத்தில் மொழி மாற்று; விளையாடும்போது கோமாளியின் அசைவின் எண்களைக் காட்டு |

நிறுத்தத்தில் B தலைப்புத் திரைக்குத் திரும்பும்; ஓட்டம் அதன் கடைசிக்
கதவிலேயே வைக்கப்பட்டிருக்கும்.

உள்ளே போகும் ஒரு வழி (கதவு, அரங்கின் திரை, பெட்டி, கடை, பாதிவழிக் கிழிசல்,
சவால் பெட்டகம்) கோமாளி அதனருகே நிற்கும்போது ஒளிர்கிறது; அழுத்த வேண்டிய
பொத்தான் அதன் மேலே தெரிகிறது.

### தலைப்புத் திரை

இரவில் அரங்கம்: ஒளிரும் திரையில் கோமாளி தாவுகிறான், பின்னால் பாவை அரசனின்
நிழல். கீழே **மூன்று சேமிப்பு இடங்கள்**. ஒவ்வொரு அட்டையும் காட்டுவது: முடித்த
ஓட்டங்கள், வைத்திருக்கும் எண்ணெய், மீட்ட ஒவ்வொரு பாவைக்கும் ஒரு மணி, அரசன்
வீடு திரும்பியிருந்தால் ஒரு நட்சத்திரம் (அவன் நிழல் கிழிந்திருந்தால் இரண்டாவது,
நீல நட்சத்திரம்), ஒரு ஓட்டம் கதவில் காத்திருந்தால் ஒரு சுடர்.

இடம் வலம் ஒரு இடத்தைத் தேர்ந்தெடுக்கும், A அதை விளையாடும், X இருமுறை அதை
அழிக்கும், SELECT மொழியை மாற்றும் (மூன்று இடங்களுக்கும் ஒரே மொழி).

## கதை

### கோமாளியும் குழுவும்

ஒரு கோயிலின் முற்றத்தில், இரவில், ஒரு நிழல் பாவைக்கூத்துக் கூடம் நிற்கிறது;
அதன் திரைத்துணி பின்னாலிருந்து ஒரு விளக்கால் ஒளிர்கிறது. ஒவ்வொரு இரவும் குழு
அதில் தன் கதைகளை ஆடுகிறது. ஒரு இரவு, பாவைகள் கதைகளிலிருந்து திரும்பவில்லை:
பாவை அரசன் அவற்றை அங்கேயே வைத்துக்கொள்கிறான், ஒவ்வொன்றையும் தான் திணித்த
ஒரு வேடத்தில். உடைந்து ஒட்டுப்போட்ட, சிரிப்புக்காக விழும் கோமாளி மட்டுமே
அவர்களைத் தேடித் திரையைக் கடக்கிறான்.

சிறைப்பட்ட பாவைகளும், அவர்கள் சிறைப்பட்ட கதைகளும்:

| கதை | அங்கே சிறைப்பட்ட பாவை |
|---|---|
| திரை | **வீரன்** (Warrior) |
| வண்ணக் காடு | **வில்** என்ற வில்லாளி (Archer) |
| தோல் கடல் | **ஆட்டக்காரி** (Dancer) |
| கொடிகளின் போர்க்களம் | **யானை** (Elephant) |
| முகமூடிச் சந்தை | **மந்திரி** (Minister) |
| விளக்கு அரண்மனை | **ராணி** (Queen), மற்றும் **பாவை அரசன்** தானே |

முதிய பாவைக்கூத்துக் கலைஞர் **ஆசான்** (Puppet Master) முற்றத்தில் தன்
பெட்டியருகே காத்திருக்கிறார். ஓட்டங்களுக்கு இடையே, எண்ணெய்க்கு, அவர்
கோமாளியைச் சீர் செய்கிறார்.

### பாவை அரசன்

விளக்கு அரண்மனையின் உச்சியில் பாவை அரசன் மூன்று அங்கங்களில் போரிடுகிறான்,
ஒரு நாடகத்தின் ஒவ்வொரு அங்கத்துக்கும் ஒன்று. ஒவ்வொரு முறை தோற்கும்போதும்
விளையாடுபவர் தேர்ந்தெடுக்கும் ஒரு பாவையை விடுவிக்கிறான்; அது பெட்டிக்குத்
திரும்புகிறது. மீட்கப்பட்ட ஒவ்வொரு பாவையும், அவன் மூன்றாம் அங்கத்தில் தனக்கென
எடுத்துக்கொள்ளும் இன்னொரு அசைவு: எத்தனை பாவைகள் வீட்டில் இருக்கிறார்களோ
அத்தனை வலிமையாகப் போரிடுகிறான். ஆறும் வீடு திரும்பியதும், அவன் விட்டுக்கொடுக்க
அவனைத் தவிர யாரும் இல்லை: இன்னொரு முறை தோற்றால், அரசனும் வீடு திரும்புகிறான்.

### பக்கங்கள்

அரசனின் கதையின் ஆறு பக்கங்கள் கதைகளில் ஒளிந்திருக்கின்றன, ஒவ்வொன்றிலும் ஒன்று.
அவை கிடைத்த வரிசையிலேயே படிக்கப்படுகின்றன, எந்தக் கதையில் கிடைத்தாலும்; அவை
அரசன் யாராக இருந்தான் என்று சொல்கின்றன: மற்ற எல்லாப் பாவைகளுக்கும் முன்னால்,
நாயகனாகச் செதுக்கப்பட்டவன், தங்கமும் வான் நீலமும் பூசப்பட்டவன்; பிறகு, குழுவுக்குத்
தோற்க ஒருவன் தேவைப்பட்டபோது, சிற்பியின் மாணவரால் கருமை பூசப்பட்டவன்; அந்த
மாணவர் பின்னர் ஒரு சிறுவனுக்கு இக்கலையைக் கற்பித்தார். அந்தச் சிறுவனே ஆசான்.
எந்த முடிவும் பக்கங்களைச் சார்ந்திருக்கவில்லை.

### முடிவுகள்

**முடிவு A.** அரசன் வீடு திரும்பும்போது, ஆசான் அவன் வண்ணத்தைச் சுரண்டுகிறார்;
அதன் அடியில் பழைய வண்ணங்கள்: ஒரு நாயகனுடையவை. திருவிழாவின் கடைசி இரவில்
குழு ஆடுகிறது; ஒரு இரவுக்கு அரசனே நாயகன். கோமாளி எப்போதும் போல் சிரிப்புக்காக
விழுகிறான்; இந்தப் பருவத்தின் மிகப் பெரிய சிரிப்பு அது.

அன்று முதல் விளையாட்டு **கடினம்**, நிரந்தரமாக (கீழே).

**முடிவு B.** கடின முறையில் அரண்மனையின் உச்சியில் அரசனின் நிழல் காத்திருக்கிறது:
அவன் மேல் தீட்டப்பட்ட கோபத்தின் கடைசித் துளி. அது கிழியும்போது, ஆசான்
கோமாளிக்கென்றே ஒரு வேடம் செதுக்குகிறார்; குழு ஐம்பது ஆண்டுகளில் முதல் புதிய
நாடகத்தை ஆடுகிறது, அதில் அரசனும் கோமாளியும் சேர்ந்து.

இரண்டு முடிவுகளும் அரங்கின் திரைத்துணியில் காட்சிகளாக ஆடப்படுகின்றன, ஒவ்வொரு
காட்சிக்கும் கீழே ஒரு வரி.

## ஒரு ஓட்டம் எப்படிப் போகிறது

1. **முற்றம்.** கோமாளி ஆசானின் பெட்டியருகே தொடங்குகிறான். பெட்டியில்,
   எண்ணெய் நிலைக்கும் சீரமைப்புகளையும், தொடக்கத்திலிருந்தே கொண்டுபோகும்
   வேடங்களுக்கான இடங்களையும், அந்த வேடங்களின் தேர்வையும் வாங்குகிறது;
   கிடைத்த பக்கங்களை அங்கே மீண்டும் படிக்கலாம்; ஒரு விதை எண்ணையும் (seed)
   தட்டச்சு செய்யலாம். அரங்கின் ஒளிரும் திரையே ஒரே கதவு: அதன் முன் மேல், ஓட்டம்
   தொடங்குகிறது.
2. **திரை** எப்போதும் முதலில், அறைக்கு ஒரு பாடம்: நடப்பதும் தாவுவதும், அடிப்பது,
   தப்புவது, திறமை, முதல் உண்மையான சண்டை, கடை, குழிகள், வீரன்.
3. **நான்கு கதைகள்** ஓட்டத்தின் **விதை எண்** தீர்மானிக்கும் வரிசையில் வருகின்றன:
   வண்ணக் காடு, தோல் கடல், கொடிகளின் போர்க்களம், முகமூடிச் சந்தை. ஒவ்வொன்றும்
   ஆறு அறைகளும் ஒரு தலைவனின் அறையும்.
4. **பாதிவழிக் கிழிசல்.** மூன்றாவது கதைக்குப் பிறகு, திரையில் ஒரு கிழிசல்
   கோமாளி கொண்டுபோகும் வேடங்களை மாற்ற விடுகிறது, ஓட்டத்துக்கு ஒருமுறை.
5. **விளக்கு அரண்மனை** எப்போதும் கடைசியில்: ஆறு அறைகள், ராணி, பிறகு பாவை
   அரசனின் மூன்று அங்கங்கள்.
6. மூன்றாம் அங்கத்தில் தோற்கும் அரசன் ஒரு பாவையை வீட்டுக்கு விடுகிறான் (அல்லது
   தானே வீடு திரும்புகிறான்); ஓட்டம் பெட்டியில் முடிகிறது.

**விழுவது.** கோமாளியின் உயிர் தீர்ந்தால், ஓட்டம் முடிகிறது: அவன் ஆசானின்
பெட்டியின் மேல் விழித்தெழுகிறான். ஓட்டத்தின் மை, தாயத்துகள், கடனாகப் பெற்ற
வேடங்கள் போய்விடும்; எண்ணெய், சீரமைப்புகள், மீட்ட பாவைகள், பக்கங்கள்
நிலைக்கும். குழியில் விழுந்தால் 10 உயிர் மட்டுமே போகும்; கடைசிப் பாதுகாப்பான
விளிம்பில் திரும்ப வைக்கப்படுவான். சவால் அறைக்குள் விழுந்தால் அதன் கதவுக்கே
திரும்புவான்; ஓட்டம் தொடரும்.

**ஒவ்வொரு கதவிலும் வைக்கப்படுகிறது.** கோமாளி ஒவ்வொரு கதவைக் கடக்கும்போதும் ஓட்டம்
வைக்கப்படுகிறது. கன்சோலை அணைத்துவிட்டு, அந்த இடத்தை மீண்டும் விளையாடும்போது,
விட்ட இடத்திலிருந்து ஓட்டத்தைத் தொடரலாமா என்று விளையாட்டு கேட்கிறது.

**விதை எண்கள்.** ஒவ்வொரு ஓட்டத்துக்கும் ஐந்து இலக்க விதை எண் உண்டு; நிறுத்தத்திலும்
முடிவிலும் காட்டப்படுகிறது. பெட்டியில் தட்டச்சு செய்த விதை எண் அந்த ஓட்டத்தை
மீண்டும் ஆடவைக்கிறது (அதே கதை வரிசை, அதே கடைகள், அதே சவால் அறைகள்), ஆனால்
எதையும் வைத்துக்கொள்வதில்லை.

## கதைகள்

ஒவ்வொரு கதைக்கும் தனி நிறங்கள், tile-கள், பின்னணி, நிழல்கள். ஒவ்வொரு நிழலும்
அடிப்பதற்கு முன் **எச்சரிக்கிறது** (ஓங்குகிறது, மின்னுகிறது, ஒளிர்கிறது அல்லது
கத்துகிறது); ஒவ்வொரு தலைவனும் ஒவ்வொரு அசைவையும் முதல் முறை இருமடங்கு நீண்ட
எச்சரிக்கையோடு காட்டுகிறான்.

| கதை | அதன் நிழல்கள் | அதன் தலைவன் |
|---|---|---|
| **திரை** | காகித வீரன் (முன்பக்கத்தைக் காக்கிறான்; பின்னாலிருந்தோ அவன் ஓயும்போதோ அடி), வைக்கோல் பொம்மைகள், மைக்கறைகள் (இரண்டாகப் பிரியும்), காகிதத் துண்டுகள் (பாய்ந்து வரும்) | **வீரன்**: மூன்று வெட்டுகள், திரட்டி ஒளிரும் கனமான வெட்டு, கேடயத்தின் பின்னால் ஒரு பாய்ச்சல் |
| **வண்ணக் காடு** | கொடிக் கைகள் (இலைகளிலிருந்து எழுந்து பிடிக்கும்), இலை அந்துப்பூச்சிகள், ஆலமர ஆவிகள் (சுவர்களின் ஊடே மிதக்கும், மறையும்) | **வில்**: குறிவைத்த அம்புகளும் அம்புத் தொடர்களும்; அருகே வந்தால் தாவி விலகுவான் |
| **தோல் கடல்** | நண்டுக் கேடயங்கள் (முன்னால் கொடுக்கை உயர்த்தி), அலை வெட்டிகள் (படித்துறையில் சவாரி), கடற்காகங்கள் (பாயும்); நீரைக் கடக்க ஏறும் படகுகள் | **ஆட்டக்காரி**: சுழலும் உதைகள், திகைக்கவைக்கும் பாய்ச்சல், அருகே வந்தால் சுழல் |
| **கொடிகளின் போர்க்களம்** | வில்லாளர் வரிசைகள் (ஒன்றாக நாணேற்றி ஒன்றாக எய்வார்கள்), கொடி தாங்கிகள் (கொடியருகே உள்ள நிழல்களுக்கு அடியில் பாதிதான் படும்), போர் முரசுகள் (தரையோடு ஓடும் அதிர்வு: தாவு) | **யானை**: சுவரிலிருந்து சுவர் பாய்ச்சல் (பிறகு மயக்கம்), தரையில் அறை |
| **முகமூடிச் சந்தை** | முகமூடித் திருடர்கள் (மை பறிப்பார்கள்; பிடித்தால் இருமடங்கு திருப்பித் தருவார்கள்), வித்தைக்காரர்கள் (உயரத்திலிருந்து கத்திகளை வீசுவார்கள்), இரட்டை முகமூடிகள் (சூரியனும் சந்திரனும், இடம் மாறும்) | **மந்திரி**: மை ஈட்டிகள், மைக் கண்ணிகள், தன் காகிதப் போலிகள் (அவனிடமிருந்து மட்டுமே மை சொட்டும்) |
| **விளக்கு அரண்மனை** | விளக்குக் காவலர்கள் (நீண்ட ஈட்டிகள்), கண்ணாடி நிழல்கள் (கோமாளியின் சொந்த நிழல், அவன் செய்வதைச் சற்றுப் பின் செய்யும்), தணல்கள் (வெடிக்கும்) | **ராணி**: விளக்குத் தீ, மூன்று அடிகள் உடைக்கும் விளக்குக் கேடயம், தீ வளையம்; பிறகு **பாவை அரசன்** |

**பாவை அரசனின் மூன்று அங்கங்கள்:** முதலாவதில் செங்கோலை வீசுகிறான், போர்வையை
உயர்த்துகிறான் (முன்பக்க அடி கோமாளியின் மேலேயே திரும்பும்), பக்கவாட்டிலிருந்து
வீரர்களை அழைக்கிறான்; இரண்டாவதில் மேலிருந்து விளக்குகள் விழுகின்றன (விழும்
இடத்தைத் தரையில் ஒரு நிழல் காட்டும்), அவன் தன் மகுடத்தை எறிகிறான், அது
திரும்பி வருகிறது; மூன்றாவதில், மீட்கப்பட்ட ஒவ்வொரு பாவையிடமிருந்தும் தான் எடுத்த
அசைவுகளால் போரிடுகிறான்.

### நிழல் தலைவர்களும் கடின முறையும்

ஒரு பாவை மீட்கப்பட்டதும், அதன் இடத்தில் அரசன் அதன் **நிழலை** வைக்கிறான்: பின்வரும்
ஓட்டங்களில் அந்தக் கதையின் தலைவன் அந்தப் பாவையின் நிழல்; இருண்டு வரையப்பட்டு,
வலிய அசைவுகளோடு; அது எந்த வேடத்தையும் கடனாகத் தருவதில்லை.

| நிழல் | அதன் வலிய அசைவுகள் |
|---|---|
| வீரனின் | மூன்று அல்ல, ஐந்து வெட்டுகள்; தூரத்திலிருந்து தாவி வெட்டு |
| வில்லின் | ஒரே நேரத்தில் விசிறியாக மூன்று அம்புகள்; கோமாளியைத் தொடரும் அம்பு மழை |
| ஆட்டக்காரியின் | பின்பிம்பங்கள்: ஒவ்வொரு உதையும் சுழலும் பாய்ச்சலும் ஒரு தாளம் கழித்து மீண்டும் அடிக்கும் |
| யானையின் | சுவரில் திரும்பி மீண்டும் பாய்கிறது; அறைக்குப் பின் கற்கள் விழுகின்றன |
| மந்திரியின் | அவன் போலிகளும் ஈட்டி எறிகின்றன; ஐந்து கண்ணிகள், நீண்ட நேரம் |
| ராணியின் | வெகு தூரத்திலிருந்து உள்ளே நெருங்கும் தீ வளையம் |

அரசன் வீடு திரும்பியதும் **கடின முறை** தொடங்குகிறது, நிரந்தரமாக. நிழல்களுக்கு
ஒன்றரை மடங்கு உயிர், ஒன்றரை மடங்கு அடி, இன்னும் அதிகம் வருகின்றன, ஒவ்வொரு
தலைவனும் ஒரு நிழல். அரண்மனையின் உச்சியில் **அரசனின் நிழல்** பாவைகளின்
அசைவுகளோடு மூன்று அங்கங்களிலும் போரிடுகிறது; அது அழைக்கும்போது, மீட்கப்பட்ட
பாவைகளில் ஒன்றின் நிழல் தன் வீரர்களோடு பக்கவாட்டிலிருந்து வந்து, தன் அசைவை
ஒருமுறை செய்து, கிழிந்துபோகிறது. மூன்றாம் அங்கத்தில் அதைக் கிழிப்பதே **முடிவு B**.

## மை, எண்ணெய், தாயத்துகள், சீரமைப்புகள்

**மை** ஓட்டத்துக்கு மட்டும்: கிழியும் நிழல்கள் மைத் துளிகளை விட்டுச்செல்கின்றன
(தலைவர்கள் நிறைய). அது ஒவ்வொரு கதையிலும் உள்ள **கடையில்** செலவாகிறது;
ஓட்டம் முடிந்தால் போய்விடும்.

| கடையில் | மை |
|---|---|
| 25 உயிர் சீர் செய் (சீரமைப்புடன் 35, 45) | 30 |
| அணிந்த வேடத்தைக் கூர்மையாக்கு: அதன் அடிகள் 20% வலுவாக, ஓட்டத்துக்கு | 80 |
| ஒரு தாயத்து (இரண்டு கொண்டுபோகலாம், சீரமைப்புடன் மூன்று) | 60 முதல் 100 |

ஒவ்வொரு கடையிலும் ஐந்தில் இரண்டு தாயத்துகள் (சீரமைப்புடன் மூன்று), ஓட்டத்தின்
விதை எண்ணும் கதையும் தீர்மானிப்பவை:

| தாயத்து | என்ன செய்யும் |
|---|---|
| சலங்கை | ஒவ்வொரு உருளலும் அடிக்கும் ஒரு வளையத்தை விடும் |
| நூல் கண்டு | குழியில் விழுந்தால் இழப்பில்லை |
| கிழிந்த பக்கம் | ஒவ்வொரு அறையிலும் முதலில் படும் அடி இரட்டிப்பு |
| விளக்குக் கரி | அடியால் கிழியும் நிழல் அருகிலுள்ளவற்றை எரிக்கும் |
| மேளத் தோல் | அடிகள் உலகை நீளமாக நிறுத்தும், வலுவாக அடிக்கும் |

**எண்ணெய்** நிலைக்கும்: தலைவர்கள் அதை விட்டுச்செல்கிறார்கள் (வீரனுக்கு 8 முதல்
அரசனுக்கு 25 வரை), சவால் பெட்டகங்களும். அது **ஆசானின் பெட்டியில்** நிலைக்கும்
சீரமைப்புகளுக்குச் செலவாகிறது; ஒவ்வொன்றும் அடுத்த ஓட்டத்திலிருந்து
செயல்படுகிறது.

| சீரமைப்பு | எண்ணெய் |
|---|---|
| கூடுதல் உயிர் (+15) | 10, 20, 40 |
| இரட்டைத் தாவல் | 25 |
| ஒவ்வொரு ஓட்டத்தையும் +50 மையுடன் தொடங்கு | 10, 20, 30 |
| தொடக்கத்திலிருந்தே கொண்டுபோகும் வேடத்துக்கு ஒரு இடம் | 20, 45 |
| சுவர்த் தாவல் | 25 |
| இரண்டாவது உருளல் | 40 |
| கடைகளில் இன்னும் 10 சீர் செய் | 15, 30 |
| மூன்றாவது தாயத்துக்கு இடம் | 50 |
| கடைகளில் இன்னும் ஒரு தாயத்து | 30 |

## ரகசியங்களும் சவால் அறைகளும்

ஒவ்வொரு கதையின் கடை அறையிலும், ஒற்றைத் தாவலுக்கு எட்டாத ஒரு விளிம்பின் மேல்,
நீலத் திரைச்சீலையுடன் ஒரு கதவு காத்திருக்கிறது. இரட்டைத் தாவல் மட்டுமே அதை
எட்டும். அதன் பின்னால் ஒரு **சவால் அறை**: கோமாளி உள்ளே நுழையும்போதே,
ஓட்டத்தின் விதை எண்ணிலிருந்தும் அவனிடமுள்ள திறமைகளிலிருந்தும் கட்டப்படுவது:

- அவன் ஏறவும் தாவவும் முடிந்த அளவுக்கு ஏற்ற சமதளம், படிகள், குழிகள்; வழியில்
  அந்தக் கதையின் நிழல்கள்;
- இரட்டைத் தாவல் இருந்தால், அது மட்டுமே ஏறும் ஒரு படி, அகலமான குழிகள்;
- சுவர்த் தாவல் இருந்தால், பத்து tile உயரப் பாறை; அதற்கும் அதன் முன்னால் தொங்கும்
  சுவருக்கும் இடையே மாறி மாறித் தாவி ஏறுவது;
- இரண்டாவது உருளல் இருந்தால், தாழ்ந்த கூரையின் கீழ் ஒரு நீண்ட குழி, இரண்டு
  உருளல்களில் கடப்பது.

அவனிடமுள்ள ஒவ்வொரு திறமையும் அறையில் எங்காவது தேவைப்படும்; அவனிடம் இல்லாத
எதுவும் கேட்கப்படாது. அங்குள்ள நிழல்கள் கிழியும்போது எதையும் விட்டுச்செல்வதில்லை.
கடைசியிலுள்ள **பெட்டகம்** ஓட்டத்துக்கு ஒருமுறை திறக்கும்: எண்ணெய், மை, அல்லது ஒரு
தாயத்து; கடின முறையில், அந்தக் கதையின் பக்கம் கிடைக்காதிருந்தால், அந்தப் பக்கம்
மட்டும், வேறொன்றும் இல்லை (கடின முறையில் பக்கங்கள் முன்பிருந்த இடங்களில் அல்ல,
சவால் அறைகளில் இருக்கும்). சவால் அறையில் விழுந்தால் ஓட்டம் முடியாது: கோமாளி
அதன் கதவுக்கே திரும்புவான்.

## இது எப்படிச் செய்யப்பட்டது

### அறைகள்

அறைகள் 8 × 8 tile-களால் Tiled-இல் செய்த வரைபடங்கள் (`.tmx`); `pulli pack`
ஒவ்வொன்றையும் `.ooru` வரைபடமாக மாற்றுகிறது. Layer 0 அறை. `things` என்ற object
அடுக்கிலுள்ள அதன் **பொருள்கள்** (objects): கோமாளி தொடங்கும் இடம், கதவுகள்,
நிழல்கள், தலைவர்கள், கடை, பெட்டி, கிழிசல், பக்கங்கள், ரகசியக் கதவுகள்;
ஒவ்வொன்றும் ஒரு புள்ளி, அதன் class அது என்ன என்று சொல்கிறது. அறை ஏறும்போது
`rooms.lua` அவற்றை `map.objects("things")` மூலம் படித்து, அவை சொல்வதை
வைக்கிறது. சவால் அறை கோமாளி நுழையும்போதே அமைக்கப்படுவதால், `challenge.lua`
அதன் பொருள்களை (கதவுகள், நிழல்கள், பெட்டகம்) அதே வடிவில் தருகிறது.

ஒவ்வொரு tile-இன் கொடிகள் `sprites.tsx`-இல்: **1**, திடமானது; **2**, மெல்லிய தரை
(மேலிருந்து நிற்கலாம், கீழிருந்து ஊடே தாவலாம், கீழ் + A-ஆல் இறங்கலாம்). ஒவ்வொரு
இடத்துக்கும் தனி tile தாள் (`screen.kolam`, `forest.kolam`, ...), அதே tile
எண்களுடன்; ஆகவே ஒரே tileset எல்லா அறைகளுக்கும்.

அறைகள் ஒரு விதியைப் பின்பற்றுகின்றன: **ஒவ்வொரு கதவுக்குமான வழியை, பிடித்த ஒரு
தாவலால் மட்டுமே, தாராளமாக ஏறலாம்**: வழியில் எந்த ஏற்றமும் மூன்று tile-க்கு
மேல் இல்லை, எந்தக் குழியும் ஆறுக்கு மேல் இல்லை. உயரமான, அகலமான இடங்கள் வழிக்கு
வெளியே வரவேற்கப்படுகின்றன (கம்பிகள், உயர் இடங்கள், இரட்டைத் தாவல் தேவைப்படும்
பக்கங்கள், ரகசியக் கதவுகள்), ஆனால் ஒரு ஓட்டத்தை ஒருபோதும் தடுப்பதில்லை. ஒரு
சோதனை ஒவ்வொரு அறையிலும் நடந்து இதைச் சரிபார்க்கிறது.

ஒரு **கதையின் கதவுகள்** அதன் வரிசையில் முன்னேறுகின்றன; அதன் கடைசிக் கதவு "next"
என்று போகிறது; ஓட்டத்தின் வரிசை அதை அடுத்த கதையாகவோ, பாதிவழிக் கிழிசலாகவோ,
முடிவாகவோ மாற்றுகிறது.

### நினைவகம்: எது படிக்கப்படுகிறது, எது விடப்படுகிறது

Lua heap 256 KB; விளையாட்டு அதற்குள் நன்றாக இருக்கும்படி கட்டப்பட்டது:

- **Code பயன்படும் இடத்தில் மட்டுமே வைக்கப்படுகிறது.** ஒரு கதையின் சொந்த நிழல்கள்
  (`forest.lua`, `sea.lua`, ...) அதன் அறைகளில் மட்டும் படிக்கப்படுகின்றன; ஒரு
  தலைவனின் code அவன் அறையில் மட்டும்; கடை, பெட்டி, வேடத் தேர்வு, சவால் அறையைக்
  கட்டுவது ஆகியவை அவற்றின் அறைகளில் மட்டும். வெளியேறும்போது code விடப்படுகிறது
  (`unrequire`).
- **ஒரு கதையின் அறைகளும் சொற்களும்** (`rooms_forest.lua`, ...) கோமாளி அந்தக் கதையில்
  அல்லது அதன் கதவருகே இருக்கும்போது படிக்கப்படுகின்றன.
- **ஒரு வேடத்தின் code** (`role_vil.lua`, ...) அது கொண்டுபோகப்படும் வரை.
- **தலைப்புத் திரை, தொடரும் கேள்வி, முடிவுகள், பக்கங்கள்** தெரியும்போது
  படிக்கப்பட்டு, பிறகு விடப்படுகின்றன.
- **விளையாடும்போது எதுவும் புதிதாகச் செய்யப்படுவதில்லை**: நிழல்கள், அம்புகள்,
  பொறிகள், துண்டுகள் தொகுப்புகளிலும் (pools) சில நீண்ட array-களிலும்.
- **ஒவ்வொரு கதவுக்குப் பின்னும் முன்கூட்டியே படித்தல்.** கதவு வழியே போகும்போது
  திரை மங்குகிறது; அந்த மங்கலுக்குப் பின்னால் அடுத்த அறை ஏறுகிறது, அதன்
  கதவுகளுக்கு அப்பாலுள்ள அறைகளும், அவற்றின் தாள்களும், code-உம், இசையும்
  முன்கூட்டியே படிக்கப்படுகின்றன (`preload`); கோமாளி விளையாடும்போது எதுவும்
  படிக்கப்படுவதில்லை.

சவால் அறை செல்களின் ஒரு அட்டவணையில் அல்ல, வரைபடத்திலேயே அமைக்கப்படுகிறது;
ஆகவே அதைக் கட்டுவது heap-க்கு ஏறக்குறைய எதுவும் செலவாவதில்லை.

### வரைதல்

ஒவ்வொரு frame-உம் இடத்தின் அசையாப் பின்னணியிலிருந்து (`backdrop`, 320 × 240
படம்) தொடங்குகிறது; பிறகு கட்டங்களாக, ஒவ்வொன்றுக்கும் ஒரு sprite தாள்:
அறையின் tile-கள், பிறகு நடிகர்கள் (கோமாளி, நிழல்கள், அறையிலுள்ள பொருட்கள்)
`actors.kolam`-இலிருந்து, பெரிய தலைவர்கள் அவர்களுடைய சொந்தத் தாள்களிலிருந்து
(`vil.kolam`, `rani.kolam`, ...). ஒவ்வொரு இடமும் தன் பன்னிரண்டு நிறங்களையும்
(20-31) அவற்றின் நிழல்களையும் அமைக்கிறது; பாத்திரங்களின் இருபது நிறங்கள் (0-19)
எங்கும் ஒன்றே. நிழல் தலைவன் என்பது அதே sprite, ஒரு இருண்ட palette வழியாக
வரையப்பட்டது.

### இசையும் ஒலிகளும்

இசை ஒரு கர்நாடக நாடக இசைக்குழு: தம்புரா சுருதி, ஆர்மோனியம், கமகங்களுடன்
நாதஸ்வரம் அல்லது புல்லாங்குழல், பதில் சொல்லும் வீணை, ஒரு தாளத்தில் மிருதங்கம்,
தவில் அல்லது கஞ்சிரா, ஜால்ரா, கோயில் மணிகள், சங்கு. ஒவ்வொரு இடத்துக்கும் தனி
இசை, அதன் சொந்த ராகத்தில்; தலைவர்களுக்கு ஒன்று, அரசனுக்கு அவனுடையது,
தலைப்புக்கும் முடிவுகளுக்கும் அவற்றுடையவை. ஒவ்வொன்றும் 44.1 kHz stereo-வில் 30
முதல் 40 வினாடி இடைவெளியில்லாத சுழல்; புதியது பழையதன் மேல் மெல்ல வருகிறது;
அடுத்த கதையினுடையது அதன் கதவுக்குப் பின்னால் முன்கூட்டியே படிக்கப்படுகிறது. ஒரே
நேரத்தில் மூன்று இசைகள் (ஒன்று மங்கும், ஒன்று ஒலிக்கும், ஒன்று முன்கூட்டியே
படிக்கப்பட்டது) ஒரு விளையாட்டு வைத்திருக்கக்கூடிய 6 MB-க்குள் அடங்குகின்றன.

இருபத்தாறு ஒலிகள் (`sfx/`, `sound.lua`-வில் பெயரிடப்பட்டவை): தாவல்கள், தரையிறங்கல்,
அடிகள், கிழியும் காகிதம், உருளல்கள், கடைகள், எடுக்கும் பொருட்கள், ஒவ்வொரு தலைவனின்
அசைவுக்கும் முன் ஒரு மணி.

பாடல்கள் உரையாக (`music/*.json`, Pattarai-இன் Isai-இல் உருவாக்கித் திருத்தப்படுபவை)
வைக்கப்படுகின்றன; அவற்றின் WAV-கள் அவற்றிலிருந்து உருவாக்கப்படுகின்றன, ஒருபோதும்
commit செய்யப்படுவதில்லை: `node tools/pattarai/make-wavs.mjs examples/nizhalattam`.
WAV-கள் இல்லாவிட்டால் விளையாட்டு ஒலியின்றி விளையாடும் (அப்போது `music()` எதுவும் செய்யாது).

### சேமிப்புகள்

மூன்று இடங்கள் (`slot1` முதல் `slot3`), எல்லாவற்றுக்குமான மொழி (`lang`). ஒரு இடம்
வைத்திருப்பது: எண்ணெய், முடித்த ஓட்டங்களும் விழுந்தவையும், சீரமைப்புகள், மீட்ட
பாவைகளும் கொண்டுபோகத் தேர்ந்த வேடங்களும், அரசன் வீடு திரும்பினானா, அவன் நிழல்
கிழிந்ததா, கிடைத்த பக்கங்கள், கடைசிக் கதவில் வைத்த ஓட்டம் (அதன் விதை எண், வரிசை,
அறை, உயிர், மை, தாயத்துகள், வேடங்கள், திறந்த பெட்டகங்கள்).

## கோப்புகள்

ஒவ்வொரு வகைக் கோப்புக்கும் அதன் சொந்தக் கோப்புறை: Lua `code/`-இல், தாள்கள்
`sprites/`-இல், பின்னணிகள் (`bg_*`) `backdrops/`-இல், அறைகளும் அவற்றின் tileset-உம்
`maps/`-இல், ஒலிகள் `sfx/`, `music/`-இல்; `manifest.lua`, `palette.hex` மேல்
மட்டத்தில். விளையாட்டு ஒவ்வொன்றையும் அதன் கோப்புப் பெயரால் மட்டுமே அழைக்கிறது.

## சோதனைகள்

`tests/test_examples.py` headless host-இல் விளையாட்டை ஆடிச் சரிபார்க்கிறது:
கோமாளியின் அசைவு (தாவல் உயரங்கள், மெல்லிய தரைகள், சுவர்கள், குழிகள், உருளல்கள்,
இரட்டை, சுவர்த் தாவல்கள்); ஒவ்வொரு வேடமும் தாயத்தும்; ஒவ்வொரு நிழலும் தலைவனும்,
அவற்றின் எச்சரிக்கைகளும், ஒவ்வொரு நிழல் தலைவனின் வலிய அசைவுகளும்; கடின முறை;
அரசனின் அங்கங்கள், அவன் நிழல், இரண்டு முடிவுகள்; கடை, பெட்டி, சீரமைப்புகள்;
பக்கங்கள்; சேமிப்புகள், இடங்கள், கதவில் வைத்த ஓட்டம்; ஒவ்வொரு கதவுக்குப்
பின்னும் முன்கூட்டியே படித்தல்; ஒவ்வொரு அறையின் கதவுகளும் மூன்று tile ஏற்றங்களால்
எட்டப்படுதல்; திறமைகளின் ஒவ்வொரு கலவைக்குமான சவால் அறைகள், நடந்தும்
ஆடியும்; இசையின் தேர்வு; ஒலிகள்; ஒவ்வொரு வரியும் இரு மொழிகளிலும் இருப்பது;
மேலும் **ஒவ்வொரு கதையிலும் Lua heap-க்கு ஒரு வரம்பு**, வளர்ச்சி முன்கூட்டியே
தெரியும்படி.

```bash
cmake -S . -B build -G Ninja && ninja -C build && (cd build && ctest --output-on-failure)
```
