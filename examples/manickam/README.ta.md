# மாணிக்கம் (Manickam)

**English:** [README.md](README.md)

*மாணிக்கம்* என்றால் ruby. இது Pulli-யின் காட்சி விளையாட்டு: தமிழிலும்
ஆங்கிலத்திலும் ஒரு சிறிய சாகசம்; ஒரு தொடக்கக் காட்சி, ஆறு அத்தியாயங்கள், நிழல்
நாகத்துடன் ஒரு இறுதிச் சந்திப்பு, முடிவில் ஒரு திருவிழா. இது கன்சோலுக்கு ஒரு
சோதனையும் கூட: தளம் அனுமதிக்கும் மிகப் பெரிய வரைபடம், முழு ஸ்பிரைட் தாள், மிகக்
கனமான காட்சிகள், உள்ளேயே ஒரு benchmark.

கயல் சண்டை போடுபவள் அல்ல. இந்த விளையாட்டில் யாரும் அடிக்கப்படுவதோ
கொல்லப்படுவதோ இல்லை. அவள் விலகி ஓடுகிறாள், பேசுகிறாள்; ஒளி மட்டுமே அவளுடைய
கருவி.

## விளையாடுதல்

முதலில் கணினிக்கான host-ஐ உருவாக்குங்கள் (repository-இன் README பாருங்கள்),
பிறகு repository-இன் மூலக் கோப்புறையிலிருந்து:

```bash
python3 tools/pulli.py run examples/manickam        # in a window, three times the size
python3 tools/pulli.py run examples/manickam 2      # a smaller window: twice the size
```

விளையாட்டு தமிழில் தொடங்குகிறது. ஆங்கிலத்துக்கு மாற, அல்லது இசையையும்
ஒலிகளையும் நிறுத்த, தலைப்புத் திரையில் **அமைப்புகள்** தேர்ந்தெடுங்கள்.

### பொத்தான்கள்

| கன்சோல் | விசைப்பலகை | விளையாட்டில் |
|---|---|---|
| D-pad | அம்புக்குறி விசைகள் | நடத்தல்; மெனுக்களில் நகர்தல் |
| A | Z | பேசுதல், விளக்கேற்றுதல், கண்ணாடியைத் திருப்புதல், மேலே படித்தல்; மெனுவில் தேர்வு |
| B | X | மின்மினி ஒளிர்கிறாள்; மெனுவில் பின்செல்லுதல் |
| X | A | மின்மினியிடம் குறிப்பு கேட்டல் |
| START | Enter | இடைநிறுத்தம் (இடைநிறுத்தத் திரை அந்தப் பகுதியின் வரைபடத்தைக் காட்டும்); காட்சியைத் தாண்டுதல் |
| SELECT | வலது Shift | விளையாடும்போது fps, cpu, நினைவகம், ஸ்பிரைட்டுகள் காட்டும்; இடைநிறுத்தத்தில் தலைப்புத் திரைக்குத் திரும்பும் |
| R | W | தலைப்புத் திரையில், benchmark இயங்கும்போது: stress x1, x2, x4 |

தலைப்புத் திரையில் SELECT, benchmark-ஐ இயக்கும், நிறுத்தும் (கீழே "Benchmark"
பகுதி பாருங்கள்). Esc சாளரத்தை மூடும்.

### தலைப்புத் திரை

- **புதிய விளையாட்டு**: தொடக்கக் காட்சி, பிறகு அத்தியாயம் 0.
- **தொடர்க**: நீங்கள் இருந்த அத்தியாயத்தின் தொடக்கத்துக்கு.
- **அத்தியாயங்கள்**: நீங்கள் அடைந்த எந்த அத்தியாயத்தையும் மீண்டும் விளையாடலாம்.
- **அமைப்புகள்**: மொழி (தமிழ் / English), இசை, ஒலிகள்.

### விளையாட்டு எப்படி

- **இதயங்கள்.** கயல் மூன்று இதயங்களுடன் தொடங்குகிறாள். இருள் உருண்டைகள்,
  முட்கள், விழும் பாறைகள், இருள் வீசும் இருண்ட குண்டுகள் ஒவ்வொன்றும் ஒரு
  இதயத்தைப் பறிக்கும்; அதன் பின் சிறிது நேரம் அவள் மின்னுகிறாள், அப்போது மேலும்
  காயம் படாது. கடைசி இதயமும் போனால் இருள் அவளைப் பிடிக்கிறது, ஆட்டம்
  முடிகிறது: A தலைப்புத் திரைக்குத் திரும்பும்; **தொடர்க** அந்த அத்தியாயத்தை
  எல்லா இதயங்களுடனும் மீண்டும் தொடங்கும். அவள் கண்டெடுக்கும் ஒவ்வொரு **இதயத்
  தாமரையும்** ஏழு வரை இன்னும் ஒரு இதயம் சேர்த்து, எல்லாவற்றையும் நிரப்புகிறது.
  அவளுடைய இதயங்கள் ஒரு அத்தியாயத்திலிருந்து அடுத்ததற்குத் தொடர்கின்றன;
  அத்தியாயங்களுக்கு இடையே பாட்டி சொல்லும் கதை ஒரு இதயத்தைத் திருப்பித் தருகிறது.
- **விளக்குகள்.** அணைந்த விளக்கின் அருகே நின்று A அழுத்தினால் அது எரியும்.
  எரியும் விளக்கின் அருகே இருள் உருண்டைகள் வராது; அதனால் எரியும் விளக்குகள்
  பாதுகாப்பான இடங்கள்.
- **மின்மினி.** மின்மினிப் பூச்சி கயலைப் பின்தொடர்ந்து இருளில் வழி காட்டுகிறாள்.
  B அழுத்தினால் அவள் ஒளிர்கிறாள்: அவள் ஒளி பெருகும், அருகிலுள்ள ஒவ்வொரு இருள்
  உருண்டையும் சுருங்கிச் சில நொடிகள் பின்வாங்கும். மீண்டும் ஒளிர அவளுக்குச்
  சிறிது நேரம் வேண்டும். குயவர் தரும் **அகல் விளக்கு** இருந்தால் மின்மினியின்
  ஒளி தூரம் போகும், விரைவில் மீண்டும் ஒளிர்வாள்.
- **இருள் உருண்டைகள்** கயலைக் கண்டதும் துரத்துகின்றன. சில நீந்தவும் செய்யும்.
- **தண்ணீர்.** ஆழமில்லாத தண்ணீர் கயலை மெதுவாக்கும். ஆழமான தண்ணீருக்குள் அவள்
  போக முடியாது.
- **முட்கள்** காயப்படுத்தும். மலையில், நிழல் பெரிதாகும் இடத்தில் **பாறைகள்**
  விழும்.
- **சாவிகளும் கோவில் வாசல்களும்.** ஒரு சாவி ஒரு வாசலைத் திறக்கும்.
- **விசைகள்** தாமரைக் குளத்தில் மூழ்கிய படிக்கற்களை மேலே கொண்டு வரும்.
- **கண்ணாடிகள்.** கோவிலில் A ஒரு கண்ணாடியைத் திருப்பும். ஒளிக்கற்றை
  கண்ணாடிகளில் பட்டுத் திரும்பி, அது சேரும் விளக்கை ஏற்றும்; கம்பிகளுக்குப்
  பின்னால் உள்ளதையும்.
- **கிடைத்தவை கிடைத்தவையே.** மாணிக்கத் துண்டுகள், சாவிகள், பானைகள், தாமரைகள்,
  இதயத் தாமரைகள் ஒரு முறை எடுத்தால் மீண்டும் தோன்றுவதில்லை.

விளையாட்டு தானே சேமிக்கிறது: ஒவ்வொரு அத்தியாயத்துக்குப் பிறகும்,
checkpoint-களிலும், ஏதாவது மாறிய ஒரு நிமிடத்துக்குள்ளும்.

## கதை

### தொடக்கம்: திருவிழாவுக்கு முந்தைய இரவு

நாளை கார்த்திகை தீபம், விளக்குகளின் திருவிழா. கயலூர்க் கோவில் மண்டபத்தில், பழைய
விளக்குக்காரியான பாட்டி, தன் பேத்தி கயலிடம் ஒவ்வொரு விளக்கையும் பளபளக்கத்
துடைக்கச் சொல்கிறாள். அவர்களுக்கு மேலே **நாக மாணிக்கம்** ஒளிர்கிறது; ஊர்
தோன்றிய நாள் முதல் இருளை விரட்டி வரும் மாணிக்கம் அது.

மண்டபத்தில் ஒரு காற்று வீசுகிறது; ஒவ்வொரு விளக்கும் அணைகிறது. கோவில் குளத்திலிருந்து
**இருள்** எழுகிறது, நிழலால் ஆன ஒரு நாகம். "எங்கும் வெளிச்சம். எனக்கு இடமே
இல்லை." அது மாணிக்கத்தைச் சுற்றிச் சுருண்டு அதை உடைக்கிறது; ஏழு துண்டுகள்
நிலமெங்கும் பறக்கின்றன.

இருளில் ஒரு சிறிய ஒளி தோன்றுகிறது: ஒவ்வொரு துண்டும் எங்கே விழுந்தது என்று
பார்த்த **மின்மினி** என்ற மின்மினிப் பூச்சி. "என் ஒளியைப் பின்தொடர்." பாட்டி
கயலை வழியனுப்புகிறாள்: திருவிழா இரவுக்குள் துண்டுகளைக் கொண்டு வா.

| 3 | **தாமரைக் குளம்** | இரண்டு துண்டுகள் தீவுகளில் கிடக்கின்றன. இருளில் படிக்கற்கள் மூழ்கிவிட்டன; பழைய விசைகளை மிதித்தால் அவை மேலே வரும். இங்குள்ள இருள் உருண்டைகள் நீந்தும். குளத்தைச் சுற்றி ஏழு தாமரைகள் பூக்கின்றன; பாட்டிக்குத் தாமரை பிடிக்கும். |
| 4 | **முள்ளு மலை** | முட்கள், பள்ளத்தாக்கில் விழும் பாறைகள். இரண்டு துண்டுகளும் இருண்ட குகைகளில் கிடக்கின்றன; அங்கே மின்மினியே ஒரே ஒளி. இரண்டாவதை கயல் எடுக்கும்போது இருள் குகையை இடிக்கிறது; சுற்றிலும் பாறைகள் விழ, மறுமுனை வாசலுக்கு ஓட அவளுக்கு ஒரு நிமிடம். |
| 5 | **கோவில்** | கோபுரத்தின் ஆறு தளங்கள் வழியே மேலே. ஒவ்வொரு தளத்தின் விளக்குகள் எல்லாம் எரிந்தால்தான் மேலே போகும் வழி திறக்கும்; சில விளக்குகளைக் கண்ணாடிகள் திருப்பும் ஒளிக்கற்றையால் மட்டுமே அடைய முடியும். கடைசித் துண்டு உச்சியில்; இருளும் அங்கேதான். |
| 6 | **கார்த்திகை தீபம்** | திருவிழா. |

### இருள்

கோபுர உச்சியில் இருள் பெரிய விளக்கைச் சுற்றிச் சுருண்டிருக்கிறது. கயல் அதனுடன்
சண்டை போடுவதில்லை. மூன்று கட்டங்களில், அது வீசும் இருண்ட குண்டுகளைத்
தவிர்த்தபடி நான்கு விளக்குகளை ஏற்றுகிறாள்: முதலில் கையால், பிறகு கண்ணாடிகளைத்
திருப்பி ஒளியைக் கொண்டு சென்று, பிறகு இருள் அவற்றை அணைத்த பின் மீண்டும் கையால்.
விளக்கொளியை அடையும் குண்டு மறைந்துவிடும்; ஒவ்வொரு கட்டமும் இருளைச் சிறிதாக்குகிறது.

கட்டங்களுக்கு இடையே அவர்கள் பேசுகிறார்கள். இவ்வளவு உயரம் ஏன் ஏறி வந்தாய் என்று
இருள் கேட்கிறது. பெரிய விளக்கை ஏற்ற, ஊருக்கு அது வேண்டும் என்கிறாள் அவள்.
ஒவ்வொரு ஆண்டும் திருவிழா இன்னும் ஜொலிக்கும்போது இருள் எங்கே போகும் என்று அது
கேட்கிறது. இரவுக்கும் இருள் வேண்டும், அது இல்லாவிட்டால் நட்சத்திரங்களே தெரியாது
என்கிறாள் கயல். அவளுக்கு அதன் மேல் வெறுப்பு இல்லை; விளக்குகள் மட்டும் திரும்ப
வேண்டும். அமைதியாகி, சிறிதாகி, இருள் மலைக்கு அடியிலுள்ள குளிர்ச்சிக்கும்
அமைதிக்கும் திரும்புகிறது; இரவு மீண்டும் அதனுடையது.

### கார்த்திகை தீபம்

மாணிக்கம் முழுதாகிவிட்டது. பெரிய விளக்கை ஏற்றச் சொல்கிறாள் பாட்டி; ஒளி
கயலூர் முழுவதும் விளக்கிலிருந்து விளக்குக்கு ஓடுகிறது. தெருவின் இரு பக்கமும்
அகல் விளக்குகள் வரிசையாக எரிகின்றன, ஊர் மக்கள் வெளியே வருகிறார்கள், நன்றி
வரிகள் மேலே எழும்போது வாணவேடிக்கை வானில் வெடிக்கிறது. கயல் ஏழு தாமரைகளையும்
கண்டெடுத்திருந்தால், அவை கோவிலை இன்னும் அழகாக்குகின்றன.

### பாட்டி சொன்ன கதைகள்

அத்தியாயங்கள் 1 முதல் 5 வரை ஒவ்வொன்றுக்குப் பிறகும், பாட்டி சொன்ன ஒரு கதையைக்
கயல் நினைவுகூர்கிறாள்:

1. புயலில் ஒரு விளக்குக்காரன் அடைக்கலம் தந்த நாகராஜன், நன்றியாக மாணிக்கத்தைத்
   தந்தது.
2. மின்மினிகள் ஒரு காலத்தில் நட்சத்திரங்கள்; பூமியை மிகவும் நேசித்ததால் வானில்
   இருக்க முடியவில்லை.
3. கார்த்திகையில் கோவிலுக்கு ஏன் தாமரை: சேற்றில் வளர்ந்தாலும் தூய்மையாக மலர்கிறது.
4. பகலில் இருள் மலைக் குகைகளில் ஓய்வெடுக்கிறது; அதன் தூக்கம் கலையாமல் இருக்கவே
   முட்கள்.
5. இரவும் பகலும் சகோதரிகள்; ஒன்று மட்டும் என்றும் வென்றால் உலகம் தடுமாறும்.

### வழியில்

- **குயவரின் பானைகள்** (அத்தியாயம் 1): மூன்றையும் கண்டுபிடித்தால் அகல் விளக்கு.
- **திருவிழாத் தாமரைகள்** (அத்தியாயம் 3): ஏழு.
- **இதயத் தாமரைகள்**: ஒவ்வொன்றும் இன்னும் ஒரு இதயம்.

கிடைத்த மாணிக்கத் துண்டுகள், இதயங்கள், இவை எல்லாவற்றையும் இடைநிறுத்தத் திரை
காட்டுகிறது.

| beam | 128 | ஒளிக்கற்றையை அனுப்புகிறது; டைலின் புரட்டல்கள் அதன் திசையை அமைக்கின்றன |

## அளவுக்குள் பொருந்த

Lua நினைவகம்தான் கன்சோலின் இறுக்கமான வரம்பு: 256 KB. 64-பிட் கணினியில் அதே
விளையாட்டு, வரம்பு சோதிக்கப்படும் கன்சோலில் எடுப்பதைவிட ஏறக்குறைய இரு மடங்கு
நினைவகம் எடுக்கிறது. ஒரு module ஒரு முறை ஏற்றப்பட்டால் விடுவிக்கப்படுவதில்லை;
அதனால் திருவிழா வரும்போது, வீரர் கடந்து வந்த ஒவ்வொரு அத்தியாயமும் இன்னும்
நினைவகத்தில் இருக்கும். பொருந்தும்படி விளையாட்டு எழுதப்பட்டுள்ளது:

- `core.lua` நான்கு SDK உதவி நிரல்களின் வேலையை (காட்சிகள், பொத்தான்கள்,
  மங்கல்கள், உரை) சில பெரிய function-களில் வைத்திருக்கிறது.
- ஒவ்வொரு மொழியின் சொற்களும் சரங்களின் அட்டவணையாக இல்லாமல் ஒரே நீண்ட சரம்;
  பயன்பாட்டிலுள்ள மொழி மட்டுமே ஏற்றப்படுகிறது. ஏற்றியதும் தமிழ் ஒரு எழுத்துக்கு
  ஒரு பைட்டாகச் சுருக்கப்படுகிறது.
- பொறிகள் ஐந்து சாதாரண வரிசைகளில் உள்ள இடங்கள்; ஒவ்வொன்றுக்கும் ஒரு அட்டவணை
  இல்லை.
- இருள் உருண்டைகள் பாதை தேடாமல் நேராகத் துரத்தி, சுவர்களில் சறுக்குகின்றன.
- திருவிழாவின் அகல் விளக்குகளும் கூட்டமும் அட்டவணைகளாக வைக்கப்படாமல், ஒவ்வொரு
  ஃப்ரேமிலும் சில எண்களிலிருந்து கணக்கிடப்படுகின்றன.

தாமரைக் குளத்தின் தண்ணீர் **நிறச் சுழற்சியால்** அலையடிக்கிறது: palette-இன் மூன்று
நீல நிறங்கள் நொடிக்குச் சில முறை இடம் மாறுகின்றன; அதனால் ஒரு டைலைக் கூட
மீண்டும் வரையாமல் எல்லாத் தண்ணீர் டைல்களும் அசைகின்றன. திருவிழா முழு வரைபடத்தையும்
`pal()` மூலம் palette-இன் இருண்ட பாதியில் வரைகிறது.

## Benchmark

தலைப்புத் திரையில் SELECT அழுத்துங்கள்: benchmark இயங்குவதை ஒரு குறி காட்டும்.
அதன் பிறகு விளையாட்டைத் தொடங்கினால் benchmark ஓடும்: விளையாட்டின் மிகக் கனமான
காட்சி வகைகளான ஏழு நிலையான கட்டங்கள், ஒவ்வொன்றும் குறிப்பிட்ட எண்ணிக்கையிலான
ஃப்ரேம்களுக்கு, எந்த உள்ளீடும் தேவையில்லாமல்.

| கட்டம் | வரைவது |
|---|---|
| sprites | முழுத் திரை டைல்களின் மேல் நகரும் 128 ஸ்பிரைட்டுகள் |
| sparks | பொறிகளின் வெடிப்புகள் |
| night | நகரும் விளக்குகள் கிழிக்கும் இருண்ட திரை |
| irul | மூன்று நாகங்களும் குண்டுகளின் புயலும் |
| map | மிகப் பெரிய வரைபடம், இரு அடுக்குகளும், நகர்ந்தபடி |
| text | தமிழ் உரை |
| sound | இசைக்கு மேல் எல்லா ஒலி அலைவரிசைகளும் இயங்கியபடி |

ஒவ்வொரு கட்டத்தின் முடிவிலும் ஒரு வரி `dbg()`-க்குப் போகிறது: கணினியில்
டெர்மினலுக்கு, board-இல் USB serial-க்கு:

```
bench <stage> frames=<n> cpu_avg=<%> cpu_max=<%> fps_min=<n> mem_peak=<KB>
```

`cpu` என்பது அந்தக் கட்டம் பயன்படுத்திய 60 fps ஃப்ரேமின் பங்கு; 100-ஐத் தாண்டினால்
அது 60 fps-ஐ விட மெதுவாக ஓடியது. Benchmark இயங்கும்போது தலைப்புத் திரையில் R,
ஒரு கருவி எங்கே தோற்கிறது என்று கண்டுபிடிக்க, தளத்தின் வரம்புகளைத் தாண்டி stress-ஐ
x2, x4 ஆக உயர்த்தும். Random எண்கள் ஒவ்வொரு முறையும் ஒரே மாதிரி விதைக்கப்படுவதால்,
ஒவ்வொரு கருவியும் அதே ஃப்ரேம்களை ஓட்டுகிறது; முடிவுகளை ஒப்பிடலாம். கடிகாரம் இல்லாத
port, cpu-வையும் fps-ஐயும் "n/a" என்று காட்டும்.

- இருண்ட காட்டில் ஒரு நிமிடம் ஒளிர்ந்தும் நினைவகம் தீராமல் இருத்தல்;
- பிடிபடுதல், ஆட்டம் முடிந்த திரை, தலைப்புத் திரைக்குத் திரும்பும் வழி;

  தருதல்;

  நினைவகத்துக்குள் பொருந்துதல்;
