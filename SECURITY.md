# Security

Pulli runs games from `.pulli` packages, reads cartridges and SD cards, and
serves Pattarai's workshop on the local machine, so a fault in reading a
package or in the workshop's server could matter.

## Reporting a problem

Please report a security problem privately, not in a public issue:

- through GitHub's **Report a vulnerability** button on the repository's
  Security tab, or
- by email to **vishwell08@gmail.com**.

Say what is affected, how to reproduce it, and what it lets someone do.
You will get a reply within a week. Once it is fixed, the fix is released
and you are credited, unless you would rather not be.

## Supported versions

Pulli has not had a release yet; fixes go to `main`.
