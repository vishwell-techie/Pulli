# நூல்: Pulli-க்கு விளையாட்டுகள் உருவாக்குதல்

**English:** [README.md](../README.md)

நூல் என்பது Pulli-க்கு விளையாட்டுகள் எழுதுவதற்கான வழிகாட்டி. ஒரு Pulli
விளையாட்டு என்பது Lua நிரல், படங்கள், ஒலிகள் அடங்கிய ஒரு கோப்புறை. அது
மடிக்கணினியில் ஓடுவது போலவே கன்சோலிலும் அப்படியே ஓடும்.

Pulli-க்குப் புதியவரா? முதலில் தொடங்குதல் பக்கத்தைப் படியுங்கள், பிறகு
பயிற்சியைப் பின்பற்றுங்கள். ஒரு மதிய நேரம் போதும்; முடிவில் கிடைக்கும்
விளையாட்டு `examples/catch`-இல் இருக்கிறது.

எண்களில் கன்சோல்: 320 × 240 திரை, 64 நிறங்கள், 8 × 8 கட்டங்களால் ஆன
ஸ்பிரைட்டுகள், நொடிக்கு 60 ஃப்ரேம்கள், 12 பொத்தான்கள், 8 ஒலி அலைவரிசைகளும்
அதன் மேல் இசையும், உங்கள் Lua நிரலுக்கும் தரவுக்கும் 256 KB வரை நினைவகம்; பேக்கேஜில் ஒரே நேரத்தில் 6 MB வரை.
`docs/SPEC.md` முழுமையான தள ஒப்பந்தம்; Pulli-ஐ வேறு கருவிக்குக் கொண்டு
செல்பவர்களுக்கும் அதற்குக் கருவிகள் செய்பவர்களுக்கும் உரியது (அது
ஆங்கிலத்தில் மட்டும்).

**இந்த மொழிபெயர்ப்பு பற்றி.** நிரல், கட்டளைகள், ஃபங்ஷன் பெயர்கள்,
பொத்தான் பெயர்கள் ஆங்கிலத்திலேயே இருக்கின்றன, ஏனெனில் கன்சோல் அவற்றை
அப்படியே படிக்கிறது. நிரலில் உள்ள குறிப்புகளும் (`--` க்குப் பின் வருபவை)
ஆங்கிலப் பக்கங்களில் உள்ளபடியே உள்ளன, அதனால் இரண்டு மொழிகளிலும் நிரல்
எழுத்துக்கு எழுத்து ஒன்றாகவே இருக்கும்.

ஆங்கிலப் பதிப்பே அதிகாரப்பூர்வமானது; இரண்டும் வேறுபட்டால் ஆங்கிலத்தைப்
பின்பற்றுங்கள்.
