# உதவி நிரல்கள்

**English:** [helpers.md](../helpers.md)

Pulli 17 உதவி நிரல்களுடன் (helpers) வருகிறது: பெரும்பாலான விளையாட்டுகளுக்குத்
தேவையானவற்றுக்காக Lua-வில் எழுதப்பட்ட சிறிய நூலகங்கள். ஒன்றைப் பயன்படுத்த,
அதை require செய்யுங்கள்:

```lua
local timer = require("timer")
```

நிறுவவோ நகலெடுக்கவோ எதுவும் இல்லை. விளையாட்டு பேக் செய்யப்படும்போது Pulli
அந்த `require`-ஐப் பார்த்து உதவி நிரலைப் பேக்கேஜில் சேர்க்கிறது.

ஒவ்வொரு உதவி நிரலும் `sdk/`-இல் உள்ள அதன் கோப்பின் மேலே உள்ள குறிப்புகளில்
தன்னை விளக்குகிறது (ஆங்கிலத்தில்); அதுவே முழு ஆவணம். அவற்றைப் பட்டியலிட:

```bash
python3 tools/pulli.py add
```

**ஒரு உதவி நிரலை மாற்றுதல்.** அதை உங்கள் விளையாட்டுக்குள் நகலெடுங்கள்; அதன்
பிறகு விளையாட்டு உங்கள் நகலைப் பயன்படுத்தும். கீழே உள்ள கட்டளை
`sdk/dialog.lua`-ஐ `mygame/`-க்குள் நகலெடுக்கிறது:

```bash
python3 tools/pulli.py add mygame dialog    # copies sdk/dialog.lua into mygame/
```

சொற்களை வரையும் உதவி நிரல்களான `text`, `dialog`, `menu` ஆங்கிலத்தைப் போலவே
தமிழையும் கையாளுகின்றன.

## நகர்தலும் வரைதலும்

| உதவி நிரல் | எதற்கு | சுருக்கமாக |
|---|---|---|
| `move` | சுவர்களைக் கடக்காமல் வரைபடத்தில் நகர்தல் | `move.by(player, dx, dy)` |
| `camera_follow` | வீரரைப் பின்தொடரும் கேமரா | `cam:update(x, y, dt)` பிறகு `cam:apply()` |
| `anim` | பெயரிட்ட ஸ்பிரைட் அசைவூட்டங்கள் | `hero:play("walk")`, `hero:draw(x, y)` |
| `tween` | ஒரு மதிப்பை இலக்கை நோக்கி மென்மையாக நகர்த்துதல் | `tween.to(box, { x = 200 }, 0.5)` |
| `particles` | தீப்பொறி, தூசி, புகை | `sparks:emit(x, y, 12, style)` |
| `transition` | திரைகளுக்கு இடையே மங்கல் மாற்றம் | `transition.through(0.6, load_next_level)` |
| `text` | நடுவில் வைத்த, வெளிக்கோடிட்ட உரை, கடிகாரங்கள் | `text.center("GAME OVER", 100, 8)` |

## விளையாட்டின் அமைப்பு

| உதவி நிரல் | எதற்கு | சுருக்கமாக |
|---|---|---|
| `scene` | தலைப்பு, விளையாட்டு, முடிவுத் திரைகள் | `scene.go("play")` |
| `input` | ஒரு முறை மட்டும் கணக்கிடப்படும் அழுத்தங்கள் | `input.pressed("a")` |
| `timer` | தாமதங்கள், மீள்நிகழ்வுகள், காத்திருப்பு நேரங்கள் | `timer.after(2, open_door)` |
| `menu` | தேர்ந்தெடுக்க ஒரு பட்டியல் | `menu.new({ "Start", "Quit" }, { choose = ... })` |
| `pool` | தோட்டாக்கள் போன்ற பொருட்களை மீண்டும் பயன்படுத்துதல் | `bullets:get()`, `bullets:free_at(i)` |

## உலகங்களும் கதைகளும்

| உதவி நிரல் | எதற்கு | சுருக்கமாக |
|---|---|---|
| `dialog` | கேள்விகளுடன் பேசும் கதாபாத்திரங்கள் | `dialog.say("Elder", "Welcome!")` |
| `inventory` | வீரர் சுமந்து செல்பவை | `bag:add("potion", 2)` |
| `quest` | வீரரிடம் செய்யச் சொல்லப்பட்டவை | `quest.advance("gems")` |
| `pathfind` | சுவர்களைச் சுற்றி வழி கண்டுபிடிக்கும் எதிரிகள் | `pathfind.find(x1, y1, x2, y2)` |
| `store` | ஒரு டேபிளைச் சேமிப்புத் தரவில் வைத்தல், பழைய சேமிப்புகளிலிருந்தும் படித்தல் | `store.save("settings", t)` |

## எடுத்துக்காட்டுகள்

- `examples/hello` `input`, `text` பயன்படுத்துகிறது.
- பயிற்சி விளையாட்டான `examples/catch` `timer`, `scene`, `text`, `particles`
  பயன்படுத்துகிறது.
- `examples/pong` `input`, `timer`, `text`, `particles` பயன்படுத்துகிறது.
- `examples/talk` `dialog`, `inventory`, `quest`, `tween`, `particles`,
  `camera_follow`, `input`, `anim`, `text` பயன்படுத்துகிறது.
- `examples/manickam` `scene`, `input`, `move`, `pathfind`, `anim`,
  `camera_follow`, `timer`, `text`, `transition`, `particles` பயன்படுத்துகிறது.

## உதவி நிரல்களும் நினைவகமும்

ஒவ்வொரு உதவி நிரலும் உங்கள் 256 KB Lua நினைவகத்தில் கொஞ்சம் எடுத்துக்கொள்கிறது:
ஒவ்வொன்றும் சுமார் 5 முதல் 7 KB, மிகப் பெரியதான `dialog` சுமார் 15 KB.
`examples/manickam` பத்தை require செய்கிறது, மொத்தம் சுமார் 115 KB
பயன்படுத்துகிறது. `stat("mem")` எவ்வளவு பயன்பாட்டில் உள்ளது என்று காட்டும்.
