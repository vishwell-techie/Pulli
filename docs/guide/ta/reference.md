# கையேடு

**English:** [reference.md](../reference.md)

கன்சோல் ஒரு விளையாட்டுக்குத் தரும் ஒவ்வொரு ஃபங்ஷனும். `[சதுர அடைப்புக்குள்]`
உள்ள arguments-ஐ விட்டுவிடலாம்; அப்போதைய இயல்பு மதிப்பு கொடுக்கப்பட்டுள்ளது.

**வரைதல் அழைப்புகளில் எண்கள்** பின்னங்களாக இருக்கலாம்: அவை முழு பிக்சலுக்குக்
கீழ்நோக்கி முழுமையாக்கப்பட்டு −32768 முதல் 32767 வரையிலான வரம்பில்
வைக்கப்படுகின்றன. **நிறங்கள்** 0 முதல் 63 வரை, சுற்றி வரும்; அதனால் 64 மீண்டும்
நிறம் 0.

## Callbacks

இவற்றை விளையாட்டு வரையறுக்கிறது; கன்சோல் அழைக்கிறது. அனைத்தும்
விருப்பத்துக்குரியவை.

### `init()`
விளையாட்டு தொடங்கும்போது ஒரு முறை அழைக்கப்படும்.

### `update(dt)`
நொடிக்கு 60 முறை அழைக்கப்படும். `dt` கடந்த அழைப்பிலிருந்து ஆன நேரம், எப்போதும்
1/60 நொடி.

### `draw()`
ஒவ்வொரு `update`-க்குப் பிறகும் அழைக்கப்படும். கன்சோலுக்கு நேரம் போதாவிட்டால்
அது ஒரு `draw`-ஐத் தவிர்க்கும், ஒருபோதும் ஒரு `update`-ஐ அல்ல.

## வரைதல்

### `cls([c = 0])`
முழுத் திரையையும் நிறம் `c`-ஆல் நிரப்பும். பின்னணிப் படம் அமைத்திருந்தால் (கீழே
`backdrop` பார்க்கவும்), நிறம் இல்லாத `cls()` அந்தப் படத்திலிருந்து சட்டத்தைத்
தொடங்கும்.

### `pset(x, y, [c = 7])`
ஒரு பிக்சலை அமைக்கும்.

### `pget(x, y)`
`camera`-க்குப் பிறகு, `pset(x, y)` அமைக்கும் பிக்சலின் நிறம்; திரைக்கு வெளியே 0.

### `line(x0, y0, x1, y1, [c = 7])`
இரண்டு புள்ளிகளுக்கு இடையே ஒரு நேர்கோடு, இரு முனைகளும் சேர்த்து.

### `rect(x, y, w, h, [c = 7])`
`(x, y)`-இல் மேல் இடது மூலை கொண்ட, `w` அகலம், `h` உயரம் உள்ள பெட்டியின்
வெளிக்கோடு.

### `rectfill(x, y, w, h, [c = 7])`
நிரப்பப்பட்ட பெட்டி.

### `circ(x, y, [r = 1], [c = 7])`
`(x, y)`-ஐ மையமாகவும் `r` ஆரமாகவும் கொண்ட வட்டத்தின் வெளிக்கோடு.

### `circfill(x, y, [r = 1], [c = 7])`
நிரப்பப்பட்ட வட்டம்.

### `shade([c = 0], lights, [edge = 0])`
விளக்குகள் உள்ள இரவு. விளக்குகளைச் சுற்றியுள்ள இடம் தவிர மற்ற எல்லா இடத்திலும்
திரையில் (`clip` செவ்வகத்துக்குள்) `c` நிறத்தைப் பூசும். `lights` என்பது எண்களின்
பட்டியல், ஒவ்வொரு விளக்குக்கும் மூன்று: `{x1, y1, r1, x2, y2, r2, ...}`; ஒவ்வொரு
விளக்கும் `circfill(x, y, r)` வரையும் வட்டம். `edge` சில பிக்சல்களாக இருந்தால்
வெளிச்சத்தின் விளிம்பு புள்ளிகளாக வரையப்படும்; அது கூர்மையான கோட்டைவிட மென்மையாகத்
தெரியும். 64 விளக்குகள் வரை; `edge` 32 வரை இருக்கலாம்.

```lua
shade(0, {player_x, player_y, 40, lamp_x, lamp_y, 24}, 4)
```

### `print(text, [x = 0], [y = 0], [c = 7])`
திரையில் உரை எழுதும், ஆங்கிலத்திலோ தமிழிலோ இரண்டிலுமோ; அதன் மேல் விளிம்பு `y`-இல்
இருக்கும். ஆங்கில எழுத்துகள் 8 × 8 பிக்சல்கள். தமிழ் ஒரு நேரத்தில் ஒரு எழுத்தாக
(உயிர்மெய்யாக) வரையப்படும், ஒவ்வொன்றும் தனக்குத் தேவையான அகலத்தில்; தமிழ் உள்ள
ஒரு வரி 22 பிக்சல் உயரம் (`font("small")`-க்குப் பின் 16); அந்த வரியிலுள்ள
எண்கள் தமிழ் அளவில் வரையப்படும், அதிலுள்ள ஆங்கிலம் அதே வரியில் அமரும்படி
கீழே இறக்கப்படும்.
Pulli-யிடம் எழுத்து இல்லாத ஒரு குறி `?` ஆகத் தெரியும். எண்களும் மற்ற மதிப்புகளும்
உரையாக மாற்றப்படுகின்றன. அடுத்த எழுத்து வர வேண்டிய `x`-ஐத் தரும். இது திரையில்
வரைகிறது; டெர்மினலில் அச்சிட `dbg` பயன்படுத்துங்கள்.

### `text_size(text)`
`text`-ஐ வரையாமல் அதன் அகலமும் உயரமும், பிக்சல்களில்: மிக நீளமான வரியின் அகலம்,
எல்லா வரிகளின் மொத்த உயரம். உரையை நடுவில் வைக்கவோ ஒரு பெட்டியின் அளவை அமைக்கவோ
இதைப் பயன்படுத்துங்கள்; `text` உதவி நிரல் அப்படித்தான் செய்கிறது.


### `font([size = "normal"])`
தமிழ் எந்த அளவில் வரையப்பட்டு அளக்கப்படும்: `"normal"` அல்லது `"small"`.
சிறிய அளவில் ஒரு வரி 22 பிக்சலுக்குப் பதில் 16, லேபிள்களுக்கும் HUD-களுக்கும்.
`camera` போல, மாற்றும் வரை அப்படியே இருக்கும். ஆங்கில எழுத்துகளும் பொத்தான்
குறியீடுகளும் அளவு மாறாது.

### `buttons`
ஒவ்வொரு பொத்தானுக்கும் ஒரு குறியீடு உள்ள அட்டவணை: `buttons.left`, `.right`,
`.up`, `.down`, `.a`, `.b`, `.x`, `.y`, `.l`, `.r`, `.start`, `.select`.
ஒவ்வொன்றும் ஒரு எழுத்து, அதனால் எந்த மொழி உரையிலும் வைக்கலாம்:
`print("Press " .. buttons.a .. " to jump", 8, 8, 7)`. குறியீடுகள் 8 பிக்சல்
உயரம்; `start`, `select` 12 அகலம், மற்றவை 8.
### `camera([x = 0], [y = 0])`
அதன் பிறகு வரையப்படும் அனைத்தையும் `(x, y)` அளவு மேலும் இடதும் நகர்த்தும். நீங்கள்
திரையில் காட்ட விரும்பும் உலகின் மூலைக்கு இதை அமைத்து, உலகை வரைந்து, பிறகு
மதிப்பெண் போன்ற அசையாதவற்றை வரையும் முன் `camera()` அழையுங்கள். இது
`map.draw`-ஐயும் நகர்த்துகிறது.

### `clip([x], [y], [w], [h])`
திரையின் இந்தப் பெட்டிக்குள் மட்டும் வரையும். ஒன்றும் இல்லாமல் `clip()`, அல்லது
அகலமோ உயரமோ 0 என்றால், மீண்டும் எல்லா இடத்திலும் வரையும்.

### `palette([c], [r], [g], [b])`
நிறம் `c`-க்குப் புதிய தோற்றம் தரும்: `r`, `g`, `b` என்பவை 0 முதல் 255 வரையிலான
சிவப்பு, பச்சை, நீலம். `palette(c)` மட்டும், நிறம் `c`-இன் தற்போதைய சிவப்பு,
பச்சை, நீலத்தைத் திரை வைத்திருக்கும் படி தரும்: `palette(9, 255, 0, 128)`
என்பது `255, 0, 132` என்று திரும்பப் படிக்கும். ஒன்றும் இல்லாமல் `palette()`
விளையாட்டின் சொந்த நிறங்களைத் திரும்ப வைக்கும். ஒரு விளையாட்டுக்கு முழு
வண்ணத்தட்டு தருவது பற்றி [ஓவியமும் ஒலியும்](art-and-sound.md) பாருங்கள்.

### `pal([a], [b])`
இனிமேல் நிறம் `a`-ஐ நிறம் `b` ஆக வரையும். ஒன்றும் இல்லாமல் `pal()` ஒவ்வொரு
நிறத்தையும் திரும்ப வைக்கும்.

### `palt([c], [see_through = true])`
ஸ்பிரைட்டுகளில் நிறம் `c`-ஐ ஊடுருவக்கூடியதாக்கும், அல்லது இல்லாமலாக்கும்.
தொடக்கத்தில் நிறம் 0 ஊடுருவக்கூடியது. ஒன்றும் இல்லாமல் `palt()` அதைத் திரும்ப
வைக்கும்.

### `fade([amount = 0])`
முழுத் திரையையும் இருட்டாக்கும்: 0 இயல்பு, 1 கருப்பு, 0.5 பாதி. இது ஒரு அளவை
அமைக்கிறது, கூட்டுவதில்லை; வரைய எந்தச் செலவும் இல்லை.

## ஸ்பிரைட்டுகள்

### `spr(n, x, y, [w = 1], [h = 1], [flip_x = false], [flip_y = false])`
`sprites.png`-இலிருந்து ஸ்பிரைட் `n`-ஐ அதன் மேல் இடது `(x, y)`-இல் இருக்கும்படி
வரையும். `w`, `h` என்பவை `n`-இலிருந்து தொடங்கி, `w` குறுக்காகவும் `h`
கீழாகவும் உள்ள கட்டங்களின் தொகுதியை வரையும். ஊடுருவக்கூடிய நிறப் பிக்சல்கள்
வரையப்படுவதில்லை.

### `sspr(sx, sy, sw, sh, dx, dy, [dw = sw], [dh = sh])`
ஸ்பிரைட் தாளின் எந்தச் செவ்வகத்தையும், பிக்சல்களில் கொடுத்து, திரையில்
`dw` × `dh` அளவுக்கு நீட்டி வரையும்.

### `sheet.load(name)`
வேறொரு தாளிலிருந்து ஸ்பிரைட்டுகளை வரையும்: விளையாட்டின் கோப்புறையிலுள்ள
ஒவ்வொரு `.png`-உம் அதே பெயருள்ள தாளாகிறது; தொடக்கத்தில் `sprites.png`-இலிருந்து
வந்த `sprites.kolam` பயன்பாட்டில் இருக்கும். `sheet.load("cave.kolam")` அதன்பின்
`spr`, `sspr`, `map.draw` எல்லாம் `cave.png`-ஐப் பயன்படுத்தச் செய்யும். ஏற்கெனவே
வரைந்தவை அப்படியே இருக்கும். அப்படி ஒரு தாள் இல்லையென்றால் பிழை.

## வரைபடங்கள்

Tiled-இல் வரைபடங்கள் உருவாக்குவது பற்றி [ஓவியமும் ஒலியும்](art-and-sound.md)
பாருங்கள்.

### `map.load([name = "map.ooru"])`
பேக்கேஜிலிருந்து ஒரு வரைபடத்தை ஏற்றும். `map.ooru` உள்ள விளையாட்டு அது
ஏற்றப்பட்ட நிலையில் தொடங்கும். ஒரு வரைபடத்தை மீண்டும் ஏற்றினால் எந்த `map.set`
மாற்றமும் நீங்கும். அந்தப் பெயரில் வரைபடம் பேக்கேஜில் இல்லையென்றால் அது பிழை.

### `map.size()`
ஏற்றப்பட்ட வரைபடத்தின் அகலமும் உயரமும், டைல்களில்; வரைபடம் இல்லையென்றால்
`0, 0`.

### `map.draw(layer, [sx = 0], [sy = 0])`
அடுக்கு 0 அல்லது 1-ஐ அதன் மேல் இடது மூலை `(-sx, -sy)`-இல் இருக்கும்படி
வரையும்; மற்ற அனைத்தையும் போலவே `camera` இதையும் நகர்த்தும். ஒவ்வொரு
அடுக்குக்கும் வெவ்வேறு `sx, sy` கொடுத்தால் அவை வெவ்வேறு வேகத்தில் நகரும்.

### `map.get(layer, cx, cy)`
`cx` நெடுவரிசை, `cy` வரிசையில் உள்ள டைல், அதன் பின் அது குறுக்காகப் புரட்டப்பட்டதா,
மேல்கீழாகப் புரட்டப்பட்டதா என்பவை. வரைபடத்துக்கு வெளியே 0.

### `map.set(layer, cx, cy, tile, [flip_x = false], [flip_y = false])`
ஏற்றப்பட்ட வரைபடத்தின் ஒரு டைலை மாற்றும். பேக்கேஜ் மாறுவதில்லை.

### `map.flags(tile)`
Tiled-இல் அமைத்த ஒரு டைலின் flags: 0 முதல் 255 வரை ஒரு எண். `solid` என்று
குறித்த டைலுக்கு `map.flags(t) & 1` என்பது 1.

## பொத்தான்கள்

பொத்தான்களின் பெயர்கள் `"left"`, `"right"`, `"up"`, `"down"`, `"a"`, `"b"`, `"x"`,
`"y"`, `"l"`, `"r"`, `"start"`, `"select"`.

### `btn(b)`
பொத்தான் `b` அழுத்தப்பட்டிருக்கும் வரை true.

### `btnp(b)`
பொத்தான் `b` கீழே போகும் ஃப்ரேமில் true. அது அழுத்தப்பட்டே இருந்தால், 24
ஃப்ரேம்களுக்குப் பின் மீண்டும் true, அதன் பின் ஒவ்வொரு 6 ஃப்ரேமுக்கும்; அதனால்
ஒரு திசையை அழுத்திப் பிடித்தால் மெனு நகரும். `"start"`, `"select"` ஒருபோதும்
மீள்வதில்லை. குதித்தல் போன்ற ஒரு முறை மட்டும் கணக்கிட வேண்டிய அழுத்தத்துக்கு
`input` உதவி நிரலைப் பயன்படுத்துங்கள்.

## ஒலி

ஒலிக் கோப்புகளைச் சேர்ப்பது பற்றி [ஓவியமும் ஒலியும்](art-and-sound.md) பாருங்கள்.

### `sfx(n, [channel = -1])`
ஒலி விளைவு `n`-ஐ இசைக்கும். 0 முதல் 7 வரை 8 அலைவரிசைகள் உள்ளன. அலைவரிசை
கொடுக்காவிட்டால் ஒரு காலியானதையோ, அல்லது எந்த அலைவரிசையின் ஒலி மிக முன்பு
தொடங்கியதோ அதையோ பயன்படுத்தும். `sfx(-1)` எல்லா அலைவரிசைகளையும்
அமைதியாக்கும்; `sfx(-1, c)` அலைவரிசை `c`-ஐ அமைதியாக்கும்.

### `music(n, [fade_ms = 0], [loop = true])`
தடம் `n`-ஐ இசைக்கும்; ஏற்கனவே ஒலிக்கும் தடம் மெல்ல அடங்கும் அதே நேரத்தில்
இதை `fade_ms` மில்லிநொடிகளில் மெல்ல ஒலிக்கச் செய்யும்.

### `music_stop([fade_ms = 0])`
இசையை மெல்ல அடக்கி நிறுத்தும்.

### `music_pause([paused = true])`
இசையையும், அது நடுவில் இருக்கும் எந்த மங்கலையும், அசையாமல் நிறுத்தி வைக்கும்.
ஒலி விளைவுகள் தொடரும். `music_pause(false)` அதே இடத்திலிருந்து தொடரும். இசையை
நிறுத்துவதும் புதிய இசையைத் தொடங்குவதும் இடைநிறுத்தத்தை முடிக்கும்.

## சேமிப்புத் தரவு

manifest-இல் `save_target` தேவை; [தொடங்குதல்](start.md) பக்கத்தின் "சேமித்தல்"
பகுதியைப் பாருங்கள்.

### `save(key, value)`
ஒரு மதிப்பைச் சேமிக்கும். `key` என்பது எழுத்துகள், இலக்கங்கள், `_`, `-` அல்லது
`.` கொண்ட 1 முதல் 32 குறிகள். `value` என்பது எண், உரை, true/false அல்லது ஒரு
டேபிள்; `nil` அந்த key-ஐ நீக்கும். true தரும்; key அல்லது மதிப்பு
அனுமதிக்கப்படாவிட்டால் அல்லது சேமிப்புத் தரவு நிறைந்திருந்தால் false.

ஒரு டேபிளில் எண்கள், உரை, true/false, மற்ற டேபிள்கள் இருக்கலாம், நான்கு அடுக்கு
வரை உள்ளடங்கி; அதன் keys எண்கள், உரை அல்லது true/false ஆக இருக்கலாம். ஒரு
ஃபங்ஷனைக் கொண்ட, அதைவிட ஆழமாக உள்ளடங்கிய, அல்லது தன்னையே கொண்ட டேபிள்
மறுக்கப்படும். `load` ஒவ்வொரு முறையும் ஒரு புதிய டேபிளைத் தரும்.

### `load(key, [default])`
`key`-இன் கீழ் சேமித்த மதிப்பு, சேமித்த அதே வகையில்; அது இல்லையென்றால்
`default`.

### `save_commit()`
சேமிப்புத் தரவை இப்போதே எழுதும்: ஒரு சோதனைச் சாவடி. விளையாட்டு முடியும்போதும்
அது எழுதப்படுகிறது; manifest-இல் `save_mode = "auto"` இருந்தால், ஒரு மாற்றத்துக்குப்
பின் ஒவ்வொரு `save_interval` நொடிக்கும் (10 அல்லது அதற்கு மேல்). வேலை செய்தால்
true தரும். எழுதுதல் flash-ஐத் தேய்க்கிறது, அதனால் இதை உண்மையான சோதனைச்
சாவடிகளில் அழையுங்கள், ஒவ்வொரு ஃப்ரேமிலும் அல்ல.

## Modules

### `require(name)`
முதல் முறை விளையாட்டின் பேக்கேஜிலிருந்து `name.lua`-ஐ ஓட்டி அது திருப்பியதைத்
தரும், எதுவும் திருப்பாவிட்டால் true. மீண்டும் கேட்டால் அதே மதிப்பைத் தரும்.
விளையாட்டில் `name.lua` இல்லையென்றால், பேக் செய்தல் அதே பெயருள்ள உதவி நிரலைச்
சேர்க்கிறது; [உதவி நிரல்கள்](helpers.md) பாருங்கள்.

### `unrequire(name)`
ஒரு module-ஐ மறக்கச் செய்யும்; அது திருப்பியதை வேறு எதுவும் பயன்படுத்தாதபோது
அதன் நினைவகம் விடுவிக்கப்படும். அடுத்த `require(name)` கோப்பை மீண்டும்
ஓட்டும். அது ஏற்றப்பட்டிருந்தால் true தரும். வீரர் முடித்த நிலைகள் அல்லது
அத்தியாயங்களுக்குப் பயனுள்ளது.

## ஏற்றுதல்

ஒரு விளையாட்டு 64 MB வரை இருக்கலாம், ஆனால் ஒரே நேரத்தில் அதில் அதிகபட்சம்
6 MB தான் நினைவகத்தில் இருக்கும். ஒவ்வொரு பகுதியும் விளையாட்டு முதல் முறை
பயன்படுத்தும்போது படிக்கப்படும்: `require`-இல் ஒரு module, `map.load`-இல் ஒரு
வரைபடம், `sheet.load`-இல் ஒரு தாள், முதல் முறை ஒலிக்கும்போது ஒரு ஒலி.
நினைவகம் நிரம்பினால், நெடுநேரம் பயன்படுத்தாத பகுதிகள் விடப்பட்டு, தேவைப்பட்டால்
மீண்டும் படிக்கப்படும்; பயன்பாட்டிலுள்ள தாள், வரைபடம், ஒலித்துக்கொண்டிருக்கும்
ஒலிகள் எப்போதும் இருக்கும். சிறிய விளையாட்டுக்கு இது எதுவும் தெரியாது.

### `preload(name, ...)`
பகுதிகளை இப்போதே நினைவகத்தில் படிக்கும், ஏற்றுதல் திரைக்குப் பின்னால், அதனால்
விளையாட்டின் நடுவில் எதுவும் படிக்கப்படாது: `"forest.ooru"`, `"forest.kolam"`
போன்ற பேக் செய்த கோப்புப் பெயர்கள், ஒரு ஒலிக்கு `"sfx 12"` அல்லது `"music 3"`.
true தரும், அல்லது ஒரு பெயர் விளையாட்டில் இல்லையென்றால் false; மற்றவை அப்போதும்
படிக்கப்படும். ஒரு பகுதி 6 MB-ஐ விடப் பெரிதென்றால் பிழை.

### `backdrop([name])`
அசையாத பின்னணியை அமைக்கும்: திரையின் அளவே உள்ள படம், 320 × 240, உதாரணமாக
`sky.png`-இலிருந்து வரும் `"sky.kolam"`. அது ஒரு முறை படிக்கப்பட்டு வைக்கப்படும்;
நிறம் இல்லாத ஒவ்வொரு `cls()`-உம் சட்டத்தை அதிலிருந்து தொடங்கும், ஒவ்வொரு
சட்டத்திலும் அதை sprite-ஆக வரைவதைவிடப் பல மடங்கு வேகமாக. `pal()`-ஆல் மாற்றிய
நிறங்கள் அதற்கும் பொருந்தும், அதனால் மங்குதல் அதையும் இருட்டாக்கும். பெயர் இல்லாத
`backdrop()` அதை விட்டுவிடும்.

## Link

கேபிளால் இணைக்கப்பட்ட இரண்டு கன்சோல்கள் குறுகிய செய்திகளைப் பரிமாறிக்கொள்ளும்.
சாளரத்தில், ஒரே `--link` போர்ட்டுடன் இரண்டு நகல்களை ஓட்டுங்கள்:
`python3 tools/pulli.py run mygame 2 --link 7000`.

### `link.status()`
link வன்பொருள் இல்லையென்றால் `"off"`, மற்ற கன்சோலுக்காகக் காத்திருந்தால்
`"waiting"`, அல்லது `"connected"`.

### `link.side()`
இணைந்திருக்கும்போது 1 அல்லது 2, ஒவ்வொரு கன்சோலிலும் வேறுபட்டது; அதனால் யார்
முன்னின்று நடத்துவது என்று இரண்டும் ஒப்புக்கொள்ளலாம். மற்ற நேரங்களில் `nil`.

### `link.send(message)`
64 பைட்டுகள் வரையிலான உரையை அனுப்பும். ஒரு ஃப்ரேமுக்கு அதிகபட்சம் 8. இரு
வரம்புகளில் எதையாவது தாண்டினால் அல்லது இணைக்கப்படாவிட்டால் false தரும்.
`string.pack` எண்களை ஒரு செய்திக்குள் வைக்கும்.

### `link.recv()`
வந்து சேர்ந்த அடுத்த செய்தி, அல்லது `nil`. செய்திகள் முழுமையாகவும் வரிசையாகவும்
வருகின்றன, அனுப்பிய அதே ஃப்ரேமில் ஒருபோதும் இல்லை.

## அமைப்பு

### `time()`
விளையாட்டு தொடங்கியதிலிருந்து ஆன நொடிகள், ஃப்ரேம்களில் எண்ணப்பட்டவை: ஒவ்வொரு
update-இலும் சரியாக 1/60 கூடுகிறது.

### `stat(what)`
`stat("frame")`: விளையாட்டு தொடங்கியதிலிருந்து நடந்த updates. `stat("mem")`:
பயன்பாட்டில் உள்ள Lua நினைவகம், KB-இல். `stat("fps")`: கடந்த ஒரு நொடியில்
நொடிக்கு நடந்த updates. `stat("active")`: நினைவகத்திலுள்ள விளையாட்டின் பகுதிகள்,
KB-இல் (அதிகபட்சம் 6144; ஏற்றுதல் பாருங்கள்). `stat("cpu")`: கடந்த ஃப்ரேமின் நேரத்தில் `update`,
`draw` பயன்படுத்திய சதவீதம்; 100-க்கு மேல் என்றால் ஃப்ரேம் தாமதமாக ஓடியது. `fps`,
`cpu` ஆகியவை விளையாட்டு ஏன் மெதுவாக இருக்கிறது என்று கண்டுபிடிப்பதற்காக,
விளையாட்டு அவற்றின்படி செயல்படுவதற்காக அல்ல: அவை ஓட்டத்துக்கு ஓட்டம்
வேறுபடும்; அளக்க ஒரு கடிகாரம் இல்லாத இடத்தில் `nil`.

### `dbg(...)`
மதிப்புகளை, tab-ஆல் பிரித்து, டெர்மினலில் அச்சிடும். தவறுகளைக் கண்டுபிடிப்பதற்காக;
கன்சோலின் திரையில் அது எதையும் காட்டாது.

### `sys.has(feature)`
இந்தக் கன்சோலில் அந்த வசதி இருந்தால் true: `"link"`, `"wifi"`, `"cart"`,
`"rumble"` அல்லது `"video"`. கன்சோல்கள் வேறுபடுகின்றன; இவை எதுவும் இல்லாமலும்
ஒரு விளையாட்டு வேலை செய்ய வேண்டும்.

## Fixed point

துல்லியமான முடிவுகள் வேண்டும் விளையாட்டுகளுக்காக, 1/65536 பங்குகளில் விருப்பத்துக்குரிய
முழு எண் கணக்கீடு. ஒரு விளையாட்டு floats, fixed point அல்லது இரண்டையும்
பயன்படுத்தலாம், ஆனால் ஒவ்வொரு கன்சோலிலும் ஒரே விதமாக. `fix.one` என்பது 65536,
`fix.pi` என்பது 205887.

### `fix.from(n)`
ஒரு எண்ணை fixed point ஆக்கும். முழு எண் `n` என்பது `n` அலகுகள்.

### `fix.to(a)`
Fixed point-ஐ சாதாரண எண்ணாக்கும்.

### `fix.floor(a)`
முழு எண் பகுதி, கீழ்நோக்கி முழுமையாக்கியது.

### `fix.mul(a, b)`
`a` பெருக்கல் `b`.

### `fix.div(a, b)`
`a` வகுத்தல் `b`. 0-ஆல் வகுத்தல் பிழை.

### `fix.sqrt(a)`
வர்க்கமூலம். எதிர்ம எண்கள் பிழை.

### `fix.sin(a)`
ரேடியன்களில் ஒரு கோணத்தின் sine.

### `fix.cos(a)`
ரேடியன்களில் ஒரு கோணத்தின் cosine.

### `fix.atan(y, [x = fix.one])`
புள்ளி `(x, y)`-இன் கோணம், ரேடியன்களில்.

Fixed-point எண்களை `+`, `-`, `<` மூலம் கூட்டவும், கழிக்கவும், ஒப்பிடவும். ±32768-ஐத்
தாண்டினால் அனைத்தும் சுற்றி வரும்; `from`, `floor`, `mul`, `div`, `sqrt`
கீழ்நோக்கி முழுமையாக்கும், `sin`, `cos`, `atan` மிக அருகிலுள்ளதற்கு.

## Lua தானே

விளையாட்டுகளுக்கு Lua 5.4-இன் `string`, `table`, `math`, `utf8`, `coroutine`
நூலகங்களும், `pairs`, `ipairs`, `tostring`, `type` போன்ற அடிப்படை
ஃபங்ஷன்களும் கிடைக்கின்றன. `io`, `os`, `package`, `debug` இல்லை; `load` என்பது
மேலே உள்ள சேமிப்புத் தரவு ஃபங்ஷன், Lua-வினுடையது அல்ல. எண்கள் 32-பிட்: முழு எண்கள்
சுமார் ±2.1 பில்லியனைத் தாண்டினால் சுற்றி வரும், பின்னங்களுக்குச் சுமார் ஏழு
இலக்கங்கள். `math.randomseed` அழைக்கப்படும் வரை `math.random` ஒவ்வொரு ஓட்டத்திலும்
ஒரே வரிசையைத் தரும். `math.sin`, `math.cos`, `^` மற்றவை ஒவ்வொரு கணினியிலும்
சரியாக ஒரே விடைகளைத் தருகின்றன.
