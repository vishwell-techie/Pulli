# ஓவியமும் ஒலியும்

**English:** [art-and-sound.md](../art-and-sound.md)

படங்கள், வரைபடங்கள், ஒலிகள் ஆகியவை சாதாரணக் கருவிகளால் உருவாக்கப்பட்டு
விளையாட்டின் கோப்புறையில் வைக்கப்படுகின்றன. விளையாட்டு பேக் செய்யப்படும்போது,
Pulli அவற்றைக் கன்சோல் படிக்கும் வடிவங்களுக்கு மாற்றுகிறது; அவற்றை நீங்கள்
ஒருபோதும் கையாள வேண்டியதில்லை.

## வண்ணத்தட்டு

Pulli-யில் ஒவ்வொரு பிக்சலும் 0 முதல் 63 வரை எண்ணிடப்பட்ட 64 நிறங்களில் ஒன்று:

![64 நிறங்கள்](../images/palette.png)

- நிறங்கள் 32 முதல் 63 வரை, 0 முதல் 31 வரையிலானவற்றின் இருண்ட நிழல்கள், சரியாக
  32 இடைவெளியில். அதனால் `pal(c, c + 32)` ஒரு நிறத்தை அதன் நிழலாக மாற்றுகிறது;
  ஒரு ஸ்பிரைட்டை மங்கலாக்க இது எளிய வழி.
- **ஸ்பிரைட்டுகளில் நிறம் 0 ஊடுருவக்கூடியது (see-through).** திடமான கருப்புக்கு,
  அதுவும் கருப்பான நிறம் 32-ஐப் பயன்படுத்துங்கள்.
- உங்கள் ஓவிய நிரலுக்காக வண்ணத்தட்டை எழுதி, இந்த நிறங்களை மட்டும் கொண்டு
  வரையுங்கள்: GIMP, Aseprite, Krita-க்கு `.gpl`; ஒரு வரிக்கு ஒரு நிறம் `.hex`;
  8 × 8 மாதிரிப் படமாக `.png`.

  ```bash
  python3 tools/pulli.py palette pulli.gpl   # GIMP, Aseprite, Krita
  python3 tools/pulli.py palette pulli.hex   # one colour per line
  python3 tools/pulli.py palette pulli.png   # an 8 x 8 swatch
  ```

### உங்களுக்கென ஒரு வண்ணத்தட்டு

வேறு நிறங்களைப் பயன்படுத்த, `palette.hex` (ஒரு வரிக்கு ஒரு `rrggbb` நிறம்)
அல்லது `palette.gpl` (GIMP, Aseprite, Krita சேமிக்கும் வடிவம்) என்ற பெயரில்
சரியாக 64 நிறங்கள் கொண்ட ஒரு கோப்பை விளையாட்டின் கோப்புறையில் வையுங்கள்.
அப்போது விளையாட்டு அந்த நிறங்களைக் காட்டும்; `pack` உங்கள் `sprites.png`-ஐ
அவற்றுடன் பொருத்தும், அதனால் அந்த வண்ணத்தட்டை உங்கள் ஓவிய நிரலில் ஏற்றி
வரையுங்கள். நிறம் 0 இன்னும் ஊடுருவக்கூடியதே; வழிகாட்டியில் உள்ள நிற எண்கள்
உங்கள் வண்ணத்தட்டைக் குறிக்கும்.

ஒரு விளையாட்டின் வண்ணத்தட்டை, அதன் கோப்புறையிலிருந்தோ பேக் செய்த
கோப்பிலிருந்தோ, ஓவிய நிரலுக்காகத் திரும்ப எழுதலாம்:

```bash
python3 tools/pulli.py palette mygame mygame.gpl
python3 tools/pulli.py palette mygame.pulli mygame.png
```

விளையாட்டு ஓடும்போது ஒரு நிறத்தை மாற்ற, `palette(c, r, g, b)` நிறம் `c`-ஐ
0 முதல் 255 வரையிலான சிவப்பு, பச்சை, நீல மதிப்புகளுக்கு அமைக்கிறது;
`palette(c)` அதைப் படிக்கிறது; `palette()` விளையாட்டின் நிறங்களைத் திரும்ப
வைக்கிறது. இப்படி ஒரு நிறத்தைச் சுழற்றுவது தண்ணீருக்கும் நெருப்புக்கும் ஒரு
மலிவான தந்திரம்.

## ஸ்பிரைட்டுகள்

உங்கள் ஸ்பிரைட்டுகளை 8 × 8 சதுரங்களின் கட்டத்தில் வரைந்து, விளையாட்டின்
`sprites/` கோப்புறையில் `sprites.png` என்று சேமியுங்கள்.

- படத்தின் அகலமும் உயரமும் 8-இன் மடங்குகளாக இருக்க வேண்டும்; அதில் அதிகபட்சம்
  131,072 பிக்சல்கள் இருக்கலாம் (உதாரணமாக 512 × 256).
- ஸ்பிரைட்டுகள் இடமிருந்து வலமாக, பிறகு மேலிருந்து கீழாக, 0 முதல்
  எண்ணிடப்படுகின்றன. `spr(n, x, y)` எண் `n`-ஐ வரைகிறது.
- பெரிய ஸ்பிரைட் என்பது பல கட்டங்கள்: `spr(n, x, y, 2, 2)` மேல் இடது கட்டம்
  `n` ஆக உள்ள 16 × 16 ஸ்பிரைட்டை வரைகிறது.
- ஊடுருவக்கூடிய பிக்சல்கள் (பாதிக்கும் குறைவான ஒளிபுகா) நிறம் 0 ஆகின்றன.
  மற்ற ஒவ்வொரு பிக்சலும் 1 முதல் 63 வரையிலான நிறங்களில் மிக அருகிலுள்ளதாகிறது.
  ஒரு நிறம் மாற வேண்டியிருந்தால் `pack` அதைச் சொல்லும்: அதைத் தவிர்க்க
  வண்ணத்தட்டை உங்கள் ஓவிய நிரலில் ஏற்றுங்கள்.
- interlaced PNG தவிர எந்த PNG-யும் வேலை செய்யும்.

## வரைபடங்கள்

வரைபடங்கள் [Tiled](https://www.mapeditor.org) என்ற இலவச வரைபடத் திருத்தியில்
உருவாக்கப்படுகின்றன.

1. Tiled-இல் புதிய வரைபடம் உருவாக்குங்கள்: orthogonal, டைல் அளவு 8 × 8,
   infinite அல்ல.
2. `sprites.png`-இலிருந்து ஒரு tileset சேருங்கள்: டைல் அளவு 8 × 8, margin
   அல்லது spacing இல்லாமல். Tiled-இல் டைல் `n` என்பது விளையாட்டில் ஸ்பிரைட் `n`.
3. இரண்டு டைல் அடுக்குகள் வரை வரையுங்கள். முதலாவது அடுக்கு 0 ஆகி முதலில்
   வரையப்படும்; இரண்டாவது அடுக்கு 1 ஆகி அதன் மேல் வரையப்படும்.
4. வரைபடத்தை விளையாட்டின் `maps/` கோப்புறையில் `map.tmx` என்று சேமியுங்கள்;
   tileset-ஐ (`sprites.tsx`) அதன் அருகில்.

`map.ooru` உள்ள ஒரு விளையாட்டு அது ஏற்றப்பட்ட நிலையில் தொடங்கும்; அதனால் பேக்
செய்த பிறகு `map.draw(0)`, `map.draw(1)` அதை வரையும். `level2.tmx` போன்ற மற்ற
வரைபடங்கள் `map.load("level2.ooru")` மூலம் ஏற்றப்படுகின்றன.

**சுவர்களும் மற்ற டைல் பண்புகளும்.** Tiled-இன் tileset காட்சியில் ஒரு டைலைத்
தேர்ந்தெடுத்து ஒரு custom property சேருங்கள்:

- `solid`, ஒரு bool: டிக் செய்தால் அந்த டைல் ஒரு சுவர். அப்போது
  `map.flags(tile) & 1` என்பது 1; `move`, `pathfind` உதவி நிரல்கள் அதைச்
  சுவராகக் கருதுகின்றன.
- `flags`, 0 முதல் 255 வரையிலான ஒரு int, உங்கள் சொந்தப் பயன்பாட்டுக்கு: ஒவ்வொரு
  டைலுக்கும் "தண்ணீர்" அல்லது "காயப்படுத்தும்" போன்ற எட்டு ஆன்/ஆஃப் பிட்கள்.
  `examples/manickam`-இல் தண்ணீருக்கு `flags` 2, அது solid அல்ல: யார் வேண்டுமானாலும்
  உள்ளே இறங்கலாம்; வீரரை மெதுவாக்க விளையாட்டு `map.flags(tile) & 2`-ஐப்
  பார்க்கிறது.

**தெரிந்துகொள்ள வேண்டியவை:**

- டைல் 0 காலியானது; அதனால் வரைபடங்கள் தாளின் முதல் கட்டத்தை ஒருபோதும்
  வரையாது. அதை வெறுமையாக வைத்திருங்கள்.
- Tiled-இல் டைல்களைப் புரட்டலாம் (flip); சுழற்றப்பட்ட டைல்கள் மறுக்கப்படும்.
- ஒரு வரைபடத்தில் இரு அடுக்குகளிலும் சேர்த்து அதிகபட்சம் 32,768 டைல்கள்
  இருக்கலாம்; உதாரணமாக 128 × 128 கொண்ட இரண்டு அடுக்குகள்.
- Object அடுக்குகள் வரைபடத்துடன் வருகின்றன. வீரரின் தொடக்க இடம், எதிரிகள்,
  கதவுகள் போன்றவற்றை ஒரு object அடுக்கில் பொருள்களாக (புள்ளிகள், பெட்டிகள்,
  டைல்கள்) வைத்து, class-உம் சொந்தப் பண்புகளும் கொடுத்து, வரைபடம்
  ஏற்றப்படும்போது `map.objects()` மூலம் படியுங்கள். சுழற்சியும் text
  பொருள்களும் இறக்குமதி ஆவதில்லை; template-இலிருந்து உருவான பொருள்களை
  detach செய்யுங்கள்.

## தமிழில் உரை

விளையாட்டுகள் ஆங்கிலத்தோடு தமிழிலும் எழுதலாம்: தலைப்புகள், உரையாடல்கள்,
`print` வரையும் எதுவும். உங்கள் Lua கோப்பில் நேரடியாகத் தட்டச்சு செய்யுங்கள்:

```lua
print("வணக்கம்! Hello!", 8, 20, 7)     -- Tamil and English on one line
local w = text_size("மாணிக்கம்")       -- how wide it is, to centre it
print("மாணிக்கம்", 160 - w // 2, 50, 10)
```

முதல் வரி தமிழையும் ஆங்கிலத்தையும் ஒரே வரியில் எழுதுகிறது; `text_size` அகலத்தைத்
தருகிறது, அதைக் கொண்டு உரையை நடுவில் வைக்கலாம்.

- உங்கள் Lua கோப்புகளை UTF-8 ஆகச் சேமியுங்கள். இன்றைய எல்லாத் திருத்திகளும்
  வேறு விதமாகச் சொல்லாவிட்டால் அப்படியே செய்கின்றன.
- தமிழ் உள்ள ஒரு வரி 22 பிக்சல் உயரம்; அதற்கு அவ்வளவு இடம் விடுங்கள். `\n`-க்குப்
  பின் `print` இதைத் தானே செய்கிறது; எந்த உரையின் அளவையும் `text_size` சொல்லும்.
- Pulli ஒவ்வொரு எழுத்தையும் (உயிர்மெய்யை) முழுதாக வரைகிறது: கொ-வை வழக்கம் போலத்
  தட்டச்சு செய்யுங்கள், உயிர்க்குறிகள் சரியான இடத்தில் வரும்.
- `text`, `dialog`, `menu` உதவி நிரல்கள் தமிழைச் சரியாக அளந்து, வரிகளாகப் பிரித்து,
  அதற்கேற்ப வரி இடைவெளி விடுகின்றன.
- தமிழ் எழுத்துகள் Noto Sans Tamil என்ற எழுத்துருவிலிருந்து பிக்சல்களாக
  மாற்றப்பட்டவை, SIL Open Font License-இன் கீழ் உள்ளவை: அவற்றைப் பயன்படுத்தும்
  விளையாட்டுகளை இது பாதிக்காது. `docs/SPEC.md` §3, "Text" பாருங்கள்.

## ஒலி விளைவுகளும் இசையும்

விளையாட்டினுள் ஒரு `sfx` கோப்புறையிலும் ஒரு `music` கோப்புறையிலும் `.wav`
கோப்புகளை வையுங்கள்.

```
mygame/
  sfx/0-jump.wav       sfx(0)
  sfx/1-coin.wav       sfx(1)
  music/0-theme.wav    music(0)
```

- கோப்புகள் அவற்றின் பெயர் வரிசைப்படி 0 முதல் எண்ணிடப்படுகின்றன; வரிசை
  தெளிவாக இருக்கப் பெயர்களை ஒரு எண்ணுடன் தொடங்குங்கள்.
- Mono அல்லது stereo, 8 முதல் 32 பிட், நொடிக்கு 4,000 முதல் 48,000
  மாதிரிகள். சாதாரண PCM WAV மட்டும்; சந்தேகமிருந்தால் உங்கள் ஒலித் திருத்தியிலிருந்து
  "WAV, signed 16-bit PCM" ஆக ஏற்றுமதி செய்யுங்கள்.
- ஒலி விளைவுகள் அப்படியே வைக்கப்படுகின்றன. இசை நான்கில் ஒரு பங்கு அளவில்
  சேமிக்கப்படுகிறது, தரத்தில் சிறிய இழப்புடன்.
- இசை சுழன்று ஒலிக்கும். WAV கோப்பில் ஒரு loop புள்ளி குறிக்கப்பட்டிருந்தால்
  அங்கிருந்து; இல்லையென்றால் தொடக்கத்திலிருந்து. `music(0, 500)` அதை அரை
  நொடியில் மெல்ல ஒலிக்கச் செய்கிறது; `music_stop(500)` மெல்ல அடங்கச் செய்கிறது.
- ஒரே நேரத்தில் எட்டு ஒலி விளைவுகள் வரை ஒலிக்கும், அதன் மேல் இசை. அவை கூடுகின்றன,
  அதனால் கொஞ்சம் இடம் விடுங்கள்: எட்டு உரத்த ஒலிகள் ஒன்றாக ஒலித்தால் சிதையும்.

இசையைக் குறுகியதாகவும் சுழல்வதாகவும் வையுங்கள். நொடிக்கு 11,025 மாதிரிகளில்
12 நொடி loop பேக் செய்த பின் சுமார் 66 KB.
